# Changelog

## 0.1.2 - 2026-11-21

- Removed development tests from the public package and moved them outside the addon folder.
- Restricted release packaging to the manifest, three runtime Lua files and documentation.
- Added the native companion-inventory bag event filter.
- Checked runtime files for unrelated globals and game-function replacements.
- Clarified AI disclosure and attribution. Companion data and appearance settings are preserved.


## 0.1.1-test - 2026-11-19

- Added Colors & Size with seven presets and independent background, title-bar and border choices.
- Theme choices save per character and apply to all windows and companion rows.
- Moved Smaller/Larger controls into this menu with a percentage display and Reset Size.
- Added Reset Colors and /csidekick colors / /csidekick size.
- Existing companion snapshots and saved size settings are preserved.


## 0.1.0-test - 2026-11-19

- First companion dashboard with a compact roster, character selector, account
  access counts, minimization, movable window and adjustable scale.
- Added per-character recruitment, known personal quests, journal objectives,
  rapport and scan times. Unseen characters remain Unknown.
- Added shared companion level, gear quality/traits, skill bar, skill-line ranks,
  ability unlocks and passive ability status.
- Added game-data keepsake matching and real achievement criteria.
- Added local per-account/per-server snapshots and event-driven refreshes.
- First English test build; live ESO verification pending.
