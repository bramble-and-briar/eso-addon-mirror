## About OneChat

OneChat adds flexible tabs and message formatting to ESO's standard PC chat. Organize conversations by channel and customize how messages appear.

- Separate incoming and outgoing channels for each tab, with a remembered outgoing channel.
- Temporary whispers and channel changes that return to the tab's saved channel after sending.
- Timestamps, guild abbreviations and custom multiline message templates.
- Right-click message copying, with clickable player names and item and achievement links.
- Per-character, per-tab history for the last 24 hours, restored after UI reload or login.
- An option to hide friend login and logout notifications.
- Optional buttons for home travel, UI reload and interface language selection.
