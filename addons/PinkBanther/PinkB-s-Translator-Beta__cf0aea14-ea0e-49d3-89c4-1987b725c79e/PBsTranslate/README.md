# PB’s Translate 1.4.0-dev

チャット欄の英語の発言の下に、日本語訳を1行表示するESOアドオンです（自分の発言・他のプレイヤーの発言の両方）。

```
[@Someone] can you help me with this quest?
[訳] このクエストを手伝ってもらえますか？
```

ESOのアドオンは外部サーバーに接続できないため、**翻訳はすべてアドオン内で行います**。
内蔵の辞書（9,260項目。高校英語レベルの語彙を含む）と、英語の語順を日本語の語順に並べ替える小さな文法規則による**直訳調の訳**です。
意味をつかむための補助で、自然な翻訳ではありません。

## 1.4.0-dev：英語→日本語の構文解析を全面的に強化

文全体を英語として構文解析し（`Syntax.lua`）、その解析結果から日本語を組み立てる（`SyntaxGen.lua`）層を加えました。解析できた文だけをこの層で訳し、解析できない文・未知語を含む文・Cyrodiilの呼び声は、従来の文法処理にそのまま任せます。

- 名詞句（冠詞・形容詞・複合名詞・所有格・数量・「all of the …」）、前置詞句、関係節（who / which / that / 接触節）、分詞・不定詞・動名詞、疑問文（yes/no・wh・埋め込み）、助動詞・完了・進行・受け身、命令、there 構文、等位・従属節を扱います。
- 日本語側は主語の省略、は／が／に の選択、語順（時・主語・場所・目的語・様態・述語）、連体修飾、使役・授受（してもらう／してくれる）を規則で決めます。
- 個別の言い回し：「take／how long」→「〜のに約10分かかります」、「thank you (so much) for …」、「make sure …」→「〜ようにしてください」、「so you don't die」→「死なないように、…」、「N times a week」→「週にN回」、「fifty thousand」→「5万」、「worse than」などの比較、「I can't hear you」→「あなたの声が聞こえません」、「the server is down」→「ダウンしています」。
- 「finished／opened／closed」のように状態として辞書にある語も、「I finished the quest」では過去形の動詞として読みます。
- 「looking for」「made of」のように活用した句動詞を、辞書の句と動詞の活用形の両方で読みます。

`test/syntax.lua`（確認済みの訳184件と、従来処理へ戻す条件）を追加しました。自然な日本語になったのは解析できた文だけで、それ以外には従来の直訳調が残ります。

## 1.3.2-dev：日本語の言い回しを改善

- 単独の自己報告では不要な「私は」を省きます。質問、条件、対比、強調、未知語のある文では省略を抑制します。「I heal too」は「私も回復します」とします。
- 自分・自分たちから相手への現在の依頼は「〜してほしいです」と表現します。過去の必要性・第三者への言及・必要性の否定は区別して残します。
- 残数や人員募集の構造解析では「敵×2が残っています」を「敵があと2人います」、「あとヒーラー×2が必要です」を「ヒーラーがあと2人必要です」とします。人物・役割や一部の物品に数え方を設定し、未対応の名詞は従来の表記を使います。
- 訳文の一括置換は行わず、解析結果から生成します。ユーザー辞書・未知語・アイテムリンクの扱いを維持します。

`test/natural.lua` に自然な表現と意味を変えてはいけない反例を追加しました。一般的な日本語の自然さが完成したという意味ではなく、他の構文には直訳調の表現が残ります。

## 1.3.1-dev：日本語を含む発言の自動翻訳を抑止

英→日モードでは、ひらがな・カタカナ（半角を含む）・漢字を含む発言を翻訳しません。「無理w」「OKです」なども原文のまま表示します。日本語のアイテムリンクを含む発言も対象外です。日→英モードと手動の `/jp` は従来どおり使えます。

## 1.3.0-dev：英語→日本語の構造解析を追加

文を主語・動作・対象・否定・時制・場所に分解し、日本語を組み立てる解析層を追加しました。資源不足、残数、門の破壊、回復依頼など、全体を解釈できる文に適用します。その他の文には既存の文法処理を使います。

否定の範囲、unless、受け身の進行形、現在完了の否定、句動詞、関係節も改善しました。未知語とユーザー辞書の優先順位は維持します。

10 MBを目標にメモリを管理し、ユーザー辞書は合計2,000枠（動詞12枠・形容詞6枠・その他1枠）、登録文字列合計128 KiBまでに制限します。超過時は保存済みデータを削除せず、追加・取り込みを中止します。詳細・検証条件は [ENGINE_REFRESH.md](ENGINE_REFRESH.md) を参照してください。実機確認前の検証版です。

## 1.2.2-dev：日本語→英語の精度を改善

日本語→英語（チャットの「日本語→英語」モードと `/en`）を作り直しました。

- **英語→日本語の辞書を逆引きします。** 名詞・形容詞・副詞・決まり文句が約6,800語、動詞が約1,050語読めるようになりました（以前は約200語）。同じ日本語に英語が複数ある場合は、基本語を優先し、数字入りの略語や子音だけの略語は避けます。自分で登録した単語も逆引きに使い、最優先します。
- **活用を読みます。** 動詞の ます／ない／た／て／たい／可能／受け身／よう、〜ている、〜てください、〜ないで、〜なければならない、〜てくれませんか。形容詞の 〜くない／〜かった。活用の形は英語→日本語と同じ規則から作ります。
- **文の区切り方を改善しました。** 最長一致ではなく、読めない文字が最も少なくなる区切り方を選びます。「今日はいい天気」が「はい（yes）」と誤読される問題が解消しました。
- **助詞と疑問文を読みます。** は／が（主語）、を（目的語）、に／で／へ／から（場所）、か（疑問）。好き・欲しいの「〜が」は目的語として扱います。いる／ある は「there is / any 〜? / no 〜」と訳します。

| 日本語 | 英訳 |
| --- | --- |
| ケーキを食べたい | I want to eat cake |
| 何をしていますか | what are you doing? |
| 明日行けますか | can you go tomorrow? |
| このクエストは難しいですか | is this quest hard? |
| ヒーラーいますか | any healer? |
| 私はケーキが好きです | I like cake |
| 手伝ってくれませんか | could you help? |
| 少し待って | wait a little |

シロディールの号令（`チャルマン砦の正門が攻撃されている` → `chal fd lit` など）は、従来の手書きの訳を最優先で使います。逆引き辞書は初めて日本語を訳すときに作ります（約1.5MB、数十ミリ秒）。英語→日本語だけを使う場合は作りません。長い文、主語の省略が多い文、敬語の細かな違いは、引き続き直訳調になります。検証は `lua test/ja_en.lua`（68文）です。

## 1.2.1-dev：翻訳の方向を切り替え

設定画面の「翻訳の方向」で、チャットの自動翻訳を **英語→日本語**（初期設定）と **日本語→英語** から選べます。`/pbtr mode en2ja` / `/pbtr mode ja2en` でも切り替えられます。

- 日本語→英語の辞書は `/en` と同じもので、短い号令・挨拶・シロディールの呼びかけが中心です。読み取れない語は訳から抜けます。「辞書にある単語の割合」の設定は、日本語→英語でも同じように働きます。
- 「訳文のみ表示」も選んだ方向で動きます。`/jp`（英語→日本語）と `/en`（日本語→英語）は、方向の設定にかかわらず今まで通りです。

## 1.1.8-dev：短いチャットの残数・否定・リソース報告を改善

- `two enemies left` →「敵×2が残っています」。数量＋名詞＋文末の `left` を残数として解釈します。`two enemies left the keep` の「出た」や `I went left` の「左」と区別します。
- `no one is healing` →「誰も回復していません」。`no one` を否定代名詞として処理し、主語・目的語のどちらでも否定を維持します。
- `out of magicka` →「マジカが尽きています」。主語省略、過去・否定・疑問にも対応します。現在は短い独立報告で、対象はマジカ・スタミナ・ポーション・魂石・所持金・マナです。場所から外へ出る `out of the keep` は別扱いにします。
- `we don't have enough healers` →「私たちにはヒーラーが足りません」。役割の人数と物の所有を区別します。`crown` の所有表現は維持します。
- `healer is not here yet` →「ヒーラーはまだここにいません」。場所の副詞を他の副詞と一緒に読んで崩す問題を修正しました。
- `get out of the keep` →「砦から出てください」。`get out of red` は「赤い範囲から出てください」とし、否定・活用も処理します。

新規辞書キーは `no one`、`get out of`、`get out of red` の3件です。`lua test/chat_precision.lua` で46例を大小文字・シロディール内外で検証し、未知語の保持・集計とユーザー辞書の優先順位も確認します。従来の文法・スラング・共有・出力テストもLuaとLuaJITで確認しています。文法推定は限られた構文を対象としており、任意の省略文の解釈を保証するものではありません。

## 1.1.7-dev：時制・助動詞・省略形の文法精度を改善

- `couldn't heal` の過去の不能、`should have waited` の後悔、`might have left` の過去の推測を訳し分けます。`Could you heal me?` は依頼のまま扱います。
- `I'd already left` の `'d` を `had` と判定します。`I'd like to help` は `would` のままです。`'s` の `is/has` も後続語から判定します。
- `couldn't've`、`shouldn't've`、`I'd've` など二重の省略形を展開します。曲がったアポストロフィ・大文字も対象です。
- 完了形の `left` を方向の「左」と誤認する問題、`had been waiting` の過去が消える問題を修正しました。
- 助動詞と進行形・受動態を組み合わせた `might have been healing`、`must have been killed`、条件節の `if you can heal` を改善しました。
- `didn't have to`／`didn't need to` の過去・否定を維持します。

文脈判定はルールによる推定です。未来を示す `tomorrow` などがなく、依頼・条件節でもない `couldn't` は過去の不能を優先します。曖昧な省略形や、会話履歴を必要とする仮定・皮肉まで完全に理解するものではありません。

検証：`lua test/grammar_precision.lua`（LuaJITでも実行可能）。意味を確認した64文を、大文字・通常表記、シロディール内外で検証します。実機での動作は別途確認が必要です。

## 1.0.4：省略した質問・砦の方角・連続指示

短い発言の構造を読み取る規則を追加しました。

| 英文 | 訳の例 |
| --- | --- |
| any healers? | ヒーラーはいますか？ |
| any repair kits? | 修理キットはありますか？ |
| healer here | ここにヒーラーがいます |
| no healer here | ここにヒーラーはいません |
| repair roe south wall | ローベック砦の南の壁を修理してください |
| two wardens | ワーデン×2 |
| if you are ready push fd | もしあなたが準備できたら、正門を攻めてください |
| repair fd heal allies | 正門を修理してください、味方を回復してください |

- `any ...?` は疑問符と解析できた名詞・場所を手掛かりに補います。通常の文中の `any` や、未登録の名前だけからは存在を推測しません。
- `warden fd` / `go to warden` は引き続き砦名、人数を伴う `two wardens` はクラス名として扱います。
- 一部の戦闘動詞では「動作＋対象」に続く次の指示を分けます。準備状態を述べる `if` / `when` / `unless` の後の指示も、条件節と分離します。
- 「みんなが準備ができている」の助詞の重複などを整理しました。ユーザー辞書を優先する動作は維持しています。

検証は下記4コマンドで実行できます。精度テストは40件追加して計136件、既存の翻訳例は360件です。Lua 5.4とLuaJITで確認しています。複雑な省略や引用、前の発言が必要な文脈には、依然として誤訳が残る場合があります。

## 1.0.3：英語チャットの意味を保つ改善

否定・指示の対象・募集人数を中心に文法を改善しました。辞書にない語は引き続き原文のまま残します。

| 英文 | 訳の例 |
| --- | --- |
| nobody can heal | 誰も回復できません |
| keep healing | 回復し続けてください |
| stop healing me | 私を回復しないでください |
| not enough players | プレイヤーが足りません |
| lf 1 tank 2 dps | タンク×1とDPS×2を探しています |
| I want you to wait | 私はあなたに待ってほしいです |
| go to roe don't push | ローベック砦に行ってください、攻めないでください |

- `hk` は文中でも活用します。`don't hk` は「砦の修理・味方の回復・防衛維持を行わないでください」。単独の `hk` の呼びかけは従来どおりです。
- シロディールでも `a warden` / `warden healer` はクラス名として扱い、`warden fd` などの砦の呼びかけとは区別します。ユーザー辞書の指定が最優先です。
- 空白で挟まれたハイフンや長いダッシュで区切られた指示も分割します。アイテムリンク内の文字はそのまま保持します。
- `must not` と `don't have to`、人数・物の不存在、依頼の対象を区別します。

検証コマンド（アドオンのフォルダーで実行）：

```sh
lua test/run.lua
lua test/accuracy.lua
lua test/outgoing.lua
lua test/dict_check.lua
```

既存の翻訳例360件とチャット表示処理に加えて、精度の検証96件を追加しています。Lua 5.4 / LuaJITで確認済みです。これはローカル環境での検証で、ゲーム内の実測ではありません。省略が多い文・複雑な引用・文脈依存の多義語には、引き続き不自然な訳が残る場合があります。

## 使い方

入れるだけで動きます。英語の発言がチャット欄に出ると、その下に `[訳]` の行が追加されます。
訳は自分の画面にだけ表示され、送信した内容・相手の画面には影響しません。

| コマンド | 内容 |
| --- | --- |
| `/jp <英文>` | 英文を自分だけに翻訳表示（送信しない）。辞書にある単語数も表示 |
| `/pbtr` | 状態（設定・辞書の項目数・このセッションの翻訳件数・エラー） |
| `/pbtr on` / `off` | 翻訳のオン/オフ |
| `/pbtr own on` / `off` | 自分の発言を翻訳する |
| `/pbtr others on` / `off` | 他のプレイヤーの発言を翻訳する |
| `/pbtr zone on` / `off` | ゾーンチャットも翻訳する |
| `/pbtr known <0-100>` | 翻訳する条件（辞書にある単語の割合、既定0%） |
| `/pbtr only on` / `off` | 訳文のみ表示のオン/オフ（既定オフ）。翻訳できない場合は原文を表示 |
| `/pbtr color RRGGBB` | 訳文全体の文字色（例: `FFFF00` は黄色、`FFFFFF` は白）。`default` で元に戻す |
| `/pbtr add english = 日本語` | 単語・言い回しを追加（例: `/pbtr add raid night = n:レイドの夜`） |
| `/pbtr remove english` | 追加した単語を削除（内蔵の訳に戻る） |
| `/pbtr list` | 追加した単語の一覧 |

設定 → アドオン → PB’s Translate からも同じ設定を変更できます（LibHarvensAddonSettings がある場合）。

`/pbtr add` の日本語の前に品詞を付けると、文の中で文法どおりに使われます。

| 接頭辞 | 品詞 | 例 |
| --- | --- | --- |
| なし / `x:` | 決まり文句（単独で訳す） | `/pbtr add gz all = 皆さんおめでとう` |
| `n:` | 名詞 | `/pbtr add trial night = n:試練の夜` |
| `v:` | 動詞（`辞書形/活用/助詞`） | `/pbtr add tp = v:テレポートする/s` |
| `a:` | 形容詞（`/i` か `/na`） | `/pbtr add comfy = a:快適/na` |
| `adv:` | 副詞 | `/pbtr add rn = adv:今すぐ` |

設定パネルの「辞書」からも登録できます。「英語」「日本語」を入力し、品詞（そのまま・名詞・動詞の五段／一段／する・形容詞のい／な）を選んで「辞書に登録」を押します。登録した単語は「登録した単語」で選び、「選んだ単語を削除」で消せます。結果はボタンの下に表示されます。パネルで登録した単語とコマンドで登録した単語は同じものです。

`dict/Cyrodiil.lua` に、シロディールのチャットでよく使われる略語・号令を収録しています。
シロディール滞在中は、PvE と意味が違う語はこちらが優先されます（`push` は「攻める」、`hold` は「守る」、`tv` はテルヴァー、`def` は防衛）。

| チャット | 訳 |
| --- | --- |
| fd down | 正門が破られました |
| chal fd lit | チャルマン砦の正門は攻撃されています |
| bleaks ua | 侵入者の基地に奇襲 |
| push fd | 正門を攻めてください |
| need def at chal | チャルマン砦で防衛が必要です |
| zerg inc from fd | 正門から大集団インカミング |
| ball group inc bd | 裏門にボールグループインカミング |
| emp got dethroned | 皇帝は廃帝にされました |
| drop siege on the bd | 裏門に攻城兵器を置いてください |
| farm is under attack | 農場は攻撃を受けています |
| stack on crown | グループリーダーに集合 |
| who has the crown? | 誰がクラウンを持っていますか？ |
| keep is flipped | 砦は奪われています |

語の選定と訳は、PBさんからいただいた一覧と、jazbay.com のシロディール用語集（https://jazbay.com/skyrim/archives/30647）、travel-lizard.blog の「シロディール基礎」（https://travel-lizard.blog/シロディール基礎/）、UESP・Fextralife・Walks-the-Uncharted の英語の用語集を参考にしています。
訳が異なる語は、PBさんの指定を優先しています（`ua` ＝奇襲、`inc` ＝インカミング、`siege` ＝包囲攻撃、`lit` ＝攻撃されている、Aleswell ＝アレスウェル砦）。
ゲーム内のアイテム名・施設名は「シロディール基礎」の表記に合わせています（燃え盛る油、トランシタスの祠、各修理キット、攻城兵器の種類）。

主な収録語: `fd`/`bd`（正門・裏門）、`inner`/`outer`（内門・外壁）、`postern`、`rss`（資源）、farm / mine / lumbermill、
ram / cata / treb / ballista / oil / meatbag / coldfire、forward camp、`ua`（奇襲）、`lit`（攻撃されている）、`inc`（インカミング）、dethrone（廃帝）、otw / omw（向かっている途中）、flip / cap、
crown、zerg / ball group / bomber / ganker、ad / dc / ep、emp、scroll、ap / tv、IC の地区名、砦・前哨基地・町の名前（略称含む）。

**砦・基地・街の名前は日本語で表示します**（例: `chal` → チャルマン砦、`bleaks` → 侵入者の基地、`WP` → ウィンターズ・ピークス基地）。
名前をまだ登録していない場所（Kingscrest など）は、英語の名前に「砦」を付けて表示します。

ログイン時とエリア移動時に現在地を確認し、辞書の優先順位を自動で切り替えます。
シロディールとインペリアルシティではシロディール辞書、それ以外では一般・ESO辞書が優先です。
優先辞書にない単語はもう一方の辞書でも探すため、砦の略称はシロディール外でも使えます。
`/pbtr add` のユーザー辞書は、どこでも最優先です。異なる品詞の候補は文脈でも選び分けます。

| 綴り | シロディール内 | シロディール外 |
| --- | --- | --- |
| `dragon` | ドラゴンクロー砦 | ドラゴン |
| `warden` | ウォーデン砦 | ワーデン |
| `tv` | テルヴァー | テレビ |
| `mine` | 鉱山（`it is mine` は「私のもの」） | 私のもの |


## 翻訳されない発言

次の発言は翻訳しません。

- 辞書にある単語がゼロの発言。既定では未知語を原文のまま残して部分翻訳を表示します。`/pbtr known` で割合を上げた場合は、その割合に満たない発言も除外します。
- 訳しても日本語が1文字も含まれない発言（`vMA` だけ、など）。
- システムメッセージ、NPCのセリフ、他のアドオンが非表示にした発言。

旧版の60%設定は更新時に一度だけ0%へ移行します。それ以外の割合は維持します。

## 仕組み

1. `CHAT_ROUTER` の `"FormattedChatMessage"` コールバックにリスナーを1つ登録します。
   キーボード版・ゲームパッド版どちらのチャット欄もこのコールバックで行を追加しており、
   通常は原文の後に訳文を追加します。「訳文のみ表示」では、既存のチャット整形処理の結果から本文だけを置き換えます。
2. 発言を単語に分けます（`Tokenizer.lua`）。`don't` `u` `pls` などの短縮形・チャット表記を展開し、
   アイテムリンクなどの書式はそのまま訳文に残します。
3. 辞書を最長一致で引きます（`Lexicon.lua`, `dict/`）。複数語の項目（`world boss`, `thank you`）が優先され、
   見つからない単語は -s / -ed / -ing / -er などを外して引き直します。
   前後の語から名詞・動詞などの読みを選びます（`the help` は名詞、`help me` は動詞）。
4. 節ごとに「主語・助動詞・動詞・目的語・前置詞句」を読み取り、
   `主語は ＋ 副詞 ＋ 前置詞句 ＋ 目的語を ＋ 動詞` の順に並べ替えます（`Grammar.lua`）。
   時制・否定・can / want to / please などは動詞の語尾（です・ます体）に変換します（`Conjugate.lua`）。
5. `if` `because` `when` の節は日本語どおり前に移し、`but` `so` などは接続の言葉でつなぎます。

辞書ファイルは `english=日本語/活用/助詞` の1行1項目で、`dict/` にあります。
後から読み込まれるファイルが優先されるため、`dict/ESO.lua` のゲーム用語が一般的な意味より優先されます。

## 苦手なもの

- 複雑な関係節の入れ子、倒置、仮定法の大半、複雑な時制の組み合わせ（関係代名詞・関係副詞・分詞の後置修飾・比較・too … to は 0.4.23 で対応）
- 辞書にない慣用句・スラング（`/pbtr add` で補えます）
- 複数の意味を持つ単語の選び分け（文脈から推測しますが間違えることがあります）
- 地名・ダンジョン名などの固有名詞の一部は日本語版の正式名称と異なる可能性があります

## テスト

`lua test/dict_check.lua` は辞書の全項目を検査します（動詞の活用の種類と語尾の不一致、「い」で終わらないい形容詞、壊れた文字列など）。辞書を編集したら実行してください。

```bash
lua test/run.lua
```

ゲームクライアントを模したスタブでアドオンを読み込み、チャットの流れ（訳が元の行の直後に出る、対象外の発言を除外する、
エンジンのエラーでチャットが止まらない、コマンド）と、約190文（シロディール60文以上を含む）の訳の回帰テストを実行します。
`PRINT=1 lua test/run.lua` で現在の訳を一覧出力します。`lua test/engine.lua "英文"` で1文ずつ確認できます。
日本語→英語は `lua test/ja_en.lua`（翻訳例68文、区切り方、登録単語の逆引き、UTF-8の安全性）と `lua test/outgoing.lua`（/en とシロディールの号令）で検証します。

**実機（PS5）では未確認です。** 確認していただきたいのは次の3点です。

1. ログイン後 `/jp thank you for the help` で `[訳] 助けていただきありがとうございます` が表示される
2. 英語で `/say can you help me?` などを送信すると、自分の発言の下に `[訳]` 行が出る

## 試作: 日本語→英語（/en）

`/en <日本語>` で英訳し、2秒後にチャット入力欄を英文が入った状態で開きます。送信は自分で行います（アドオンからの送信はゲームの仕様で不可能）。
翻訳できなかったときは入力欄に「翻訳不可」と入ります。一部だけ訳せたときは訳せた部分を入れ、訳せなかった語はチャット欄に `未対応の語` として表示します。

- 対象は決まり文句とシロディールの号令です（例: `/en チャルマン砦の正門が攻撃されている` → `chal fd lit`、`/en 正門に破城槌が必要です` → `need rams at fd`）。
- 訳文はチャット欄にも `[en]` として表示します。
- `/en probe` は、文字の判定がゲーム内でどう動いているかを表示します（不具合調査用）。

0.4.16 では、翻訳できない日本語を入れるとPS5がクラッシュしました。日本語のバイトの一部が「英字」と判定される環境で、文字が途中で切れた不正な文字列を作っていたためと考えられます（PCで Latin-1 ロケールにすると再現します）。0.4.17 では文字の判定をすべてASCII限定にし、チャット欄や入力欄に渡す前にUTF-8として正しいか確認します。

0.4.12 でPS5がクラッシュしたため、下の確認用コマンドで入力欄の操作を1つずつ試しました（0.4.14〜0.4.15、どれもクラッシュせず）。0.4.16 の `/en` はそのうち問題のなかった手順だけを使い、入力欄が開いたままの場合は開き直さずに終わります。

| コマンド | 内容 |
| --- | --- |
| `/en try 1` | 入力欄を空で開く（PB’s ChatAssistant と同じ手順） |
| `/en try 2` | 1 のあと、3秒後に文字入力画面の状態を読む |
| `/en try 3` | 1 のあと、3秒後に入力欄の文字列を読む |
| `/en try 4` | 1 のあと、3秒後に入力欄へ `hello` を入れる |
| `/en try 5` | `hello` を入れた状態で入力欄を開く（0.4.12 の方法） |
| `/en try 6` | 5 を0.3秒後に行う（0.4.12 の待ち時間） |
| `/en try 7` | 0.4.12 と同じ操作を2秒後に行う（開いた直後と1.5秒後に文字列と入力画面の状態を読む） |
| `/en try 8` | 0.4.12 と完全に同じ（0.3秒後＋同じ操作） |

1〜8 はいずれも PS5 でクラッシュしませんでした（0.4.14〜0.4.15）。

テスト: `lua test/outgoing.lua`

0.4.24では、`defend roe hk will bone` のように句読点・接続詞が省略された発言の後半（助動詞＋動詞）を別の節として翻訳します。主動詞の後で解析できなかった単語は、読み飛ばさず原文で末尾に残します。条件関係や省略された主語を推測して補うものではありません。
