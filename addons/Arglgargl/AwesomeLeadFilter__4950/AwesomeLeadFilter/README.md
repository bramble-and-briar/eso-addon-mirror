# AwesomeLeadFilter

Adds additional filter capabilities for antiquity lead scrolls to AwesomeGuildStore by sirinsidiator.

A new filter category named 'Codex Knowledge' has been added to the Consumable / Miscellaneous sub-category. The filter allows for two options:
- Never dug out: only shows scrolls for antiquities that have never been dug out
- Codex Entries: only shows scrolls for antiquities with unknown codex entries 

If any of the filter options is active, only lead scrolls are shown.
