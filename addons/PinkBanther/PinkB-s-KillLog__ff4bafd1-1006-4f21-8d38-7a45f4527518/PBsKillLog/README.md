# PB's KillLog

PvP でプレイヤー同士のキルが起きた時に出るキルログだけを、専用ウィンドウに表示する Elder Scrolls Online 用アドオンです。自分のキル数・死亡数を日毎に記録し、階級とランキングで振り返れます。

設定 > ソーシャル の「PvP キルフィード」（チャットへのキルログ出力）が **オフでも** 表示されます。

表示・記録するのは **シロディールと帝都（Imperial City）の中だけ** です。バトルグラウンドのキルは、ゲーム本体のキルフィードには流れますが、このアドオンは無視します（ログにも出さず、記録もせず、効果音も鳴らしません）。

## 導入

`PBsKillLog` フォルダを ESO のアドオンフォルダに置きます。設定メニューには LibHarvensAddonSettings（20106 以上）が必要です。他の PB's アドオンと同じライブラリで、コンソールでも PC でも使えます。無くてもウィンドウ自体は動作し、`/pbkl` で操作できます（記録の閲覧には設定メニューが必要です。`/pbkl stats` と `/pbkl ranking` は設定メニューなしでも使えます）。

## 設定（設定 > アドオン > PB’s KillLog）

メニューは日本語クライアントでは日本語、それ以外では英語で表示されます。設定画面の各項目（サブメニュー）は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| （先頭） ここにプレビューを表示 | 設定画面を開いている間、ウィンドウの場所・大きさ・文字サイズを枠とサンプルのキルで見せる（初期値オン） |
| （先頭） ウィンドウのロックを解除 | ドラッグで移動、縁のドラッグでサイズ変更。リロード後は必ずロックに戻る。マウスが使える環境のみ（コンソールには出ない） |
| 階級 | 階級（1 種類）と、その元になる合計バトル数・勝率。次の階級まで今の勝率であと何戦かも表示 |
| ランキングウィンドウ | ランキングウィンドウの表示/非表示と、表示する期間（全期間・今日・今月・過去の月・過去の日） |
| 日別の記録 | 今日と、記録のある日ごとのキル数・死亡数（新しい順に 30 日分。それより前は件数だけ） |
| 攻撃の記録 | 期間（全期間または 1 日）を選んで、キルに使った攻撃・死亡の原因になった攻撃の上位 5 件 |
| ウィンドウ | 位置 X / Y、幅 / 高さ（5 刻み） |
| 文字 | フォントサイズ 12〜64 |
| レイヤー | 描画ティア（低 / 中 / 高）と描画レベル（0〜100） |
| サウンド | 自分がキルした時の効果音のオン/オフ（初期値オン）。オンにした時に一度鳴らして確認できる |
| ログ | テストキルの追加、ログの消去、日別の記録の消去、累計と階級のリセット |

キルログは HUD にしか描かれないため、設定画面からは見えません。そのためプレビューは、ウィンドウとは別のピンクの枠を同じ場所・大きさ・文字サイズで描きます（ChatWindowCustomizer と同じ方式）。スライダーを動かすとその場で追従します。

## 記録と階級

シロディールと帝都で起きたキルのうち、自分が撃破者のものを「キル」、自分が被撃破者のものを「死亡」として、日毎に数えます。日付は端末の時計（日本なら日本時間の 0 時）で切り替わります。

- **攻撃の記録**: キルは戦闘イベント（`ACTION_RESULT_KILLING_BLOW`）、死亡はゲームの死亡画面と同じ情報（`GetKillingAttackInfo`）から、とどめを刺した攻撃を記録します。取れなかった場合も回数は数えます。
- **プレイヤーの記録**: 倒した相手と、自分を倒した相手を、アカウント名で数えます（表示は設定の「プライマリ名」に従います）。
- **階級**: 軍隊の階級（二等兵〜元帥の 18 段階）が **1 種類** あり、**合計バトル数と勝率** から決まります。合計バトル数はキル数＋死亡数、勝率はキル数÷合計バトル数です。
- **累計は日別の記録とは別に持っています**。記録が溜まって日別の記録を消去しても、階級は残ります。階級ごとゼロに戻すには「累計と階級もリセット」を使います。どちらも確認ダイアログが出ます。

| 階級 | 必要な点数 | 階級 | 必要な点数 |
| --- | --- | --- | --- |
| 二等兵 | 0 | 少佐 | 1000 |
| 一等兵 | 5 | 中佐 | 1400 |
| 上等兵 | 15 | 大佐 | 2000 |
| 兵長 | 30 | 少将 | 3000 |
| 伍長 | 60 | 中将 | 4500 |
| 軍曹 | 100 | 大将 | 7000 |
| 曹長 | 160 | 元帥 | 10000 |
| 准尉 | 240 | | |
| 少尉 | 350 | | |
| 中尉 | 500 | | |
| 大尉 | 700 | | |

階級の点数は、次の式で出します。

> 点数 ＝ 合計バトル数 × （0.5 ＋ 勝率）

1 バトルは、勝率 0% なら 0.5 点、50% なら 1 点、100% なら 1.5 点として数えます。戦うほど、そして勝つほど、早く上がります。同じ 100 バトルでも、全勝なら 150 点（軍曹）、半分勝てば 100 点（軍曹）、1 つも勝てなければ 50 点（兵長）です。式を変えると、同じ点数の表（`RANK_THRESHOLDS`）をそのまま使えます。

点数は整数で正確に計算します（点数は「キル数＋合計バトル数÷2」と同じ値です）。割り算で出した勝率をかけると、丸め誤差で境界の点数を取りこぼすことがあるためです。次の階級までの戦数は、今の勝率がそのまま続くとして数えます（バトルがまだ無いときは勝率 50% として数えます）。

表の点数は `Records.lua` の `RANK_THRESHOLDS`、1 バトルの基本点（0.5）は `BASE_POINTS_PER_BATTLE` で変えられます。

## ランキングウィンドウ

別ウィンドウに、4 つの上位 10 件を並べます。

- 殺されたスキル（自分を倒した攻撃）
- 殺したスキル（自分がキルに使った攻撃）
- 殺されたプレイヤー（自分を倒した相手）
- 殺したプレイヤー（自分が倒した相手）

期間は **全期間・日毎・月毎** から選べます。日毎は今日または記録のある過去の日、月毎は今月または記録のある過去の月です。「今日」「今月」を選んだ場合は、日付が変わるとそのまま次の日・月に切り替わります。

文字は、画面に収まる範囲でいちばん大きいサイズを自動で選びます。使うのはコンソール UI が読み込み済みの名前付きフォント（`ZoFontGamepad34` から `ZoFontGamepad20`）だけで、各サイズの行の高さを実際に測って、10 行 × 2 段が画面（上下に余白を残す）に収まる最大のものを使います。日本語クライアントでは名前付きフォントが小さく描かれる（たとえば `ZoFontGamepad20` は 15px、`ZoFontGamepad34` は 28px）ため、数字の名前ではなく測った高さで決めています。名前が列の幅を超えるときは「…」で省略し、枠からはみ出しません。

入力を受け取らないウィンドウです（コンソールでは、入力を受ける部品がゲームのボタンを奪うため）。HUD 上では `/pbkl ranking` で出し入れし、設定画面を開いている間はその上に重ねて表示します。画面の右側に出るので、左の設定リストとは重なりません。

## スラッシュコマンド

`/pbkl unlock` `/pbkl lock` `/pbkl test` `/pbkl clear` `/pbkl reset` `/pbkl preview` `/pbkl ranking [day|month|all]` `/pbkl stats` `/pbkl sound [on|off]`

- `ranking` は引数なしで表示/非表示の切り替え。`day`（今日）・`month`（今月）・`all`（全期間）を付けると、その期間で表示します。
- `stats` は今日のキル・死亡と、階級と、その元になる合計バトル数・勝率をチャットに出します。
- `preview` は設定画面の外（HUD 上）でも枠を出し入れします。`sound` は引数なしで切り替えです。

## 仕組み

- 対象の場所は、「`IsInCyrodiil()` か `IsInImperialCity()` のどちらかが真で、バトルグラウンドではない」ことで判定します。帝都は独立したゾーン（PB's Translate の調査では、帝都で `IsInCyrodiil()` は偽）なので両方を調べ、帝都キャンペーンもこれで対象になります。公式文書には `IsInCyrodiil()` が帝都やバトルグラウンドで何を返すか書かれていないため、バトルグラウンドは `IsActiveWorldBattleground()` で明示的に除外しています。キルを受け取るたびに判定し、ログ本体の表示／非表示はロード画面のたびに切り替えます。
- `EVENT_PVP_KILL_FEED_DEATH` を直接購読します。「PvP キルフィード」設定の判定は公式チャット側（`chathandlers.lua`）のハンドラ内にあり、このアドオンは判定しません。
- 公式と同じく、ローカル由来とキル地点由来で同じキルが二重に届くため、10 秒以内の重複は 1 行にまとめます。カウントもその後に行うので、二重には数えません。
- 文面・色・ランクアイコンは公式のキルフィードと同じ文字列リソースで生成するため、言語設定に従います。
- キルの攻撃は、とどめの戦闘イベントとキルフィードの行を、3 秒以内・同じ相手名で突き合わせます（どちらが先でも対応）。戦闘イベントはエンジン側で「自分のとどめの一撃」だけに絞って受け取ります。死亡の攻撃は、ゲームが死亡画面を作るのと同じく、死亡の約 2 秒後に読み取ります。
- 日付は、このクライアントに `GetDate()` が無いため、PB's Omikuji と同じ方式（`GetTimeStamp` と `GetSecondsSinceMidnight` から現地の日を求める）で出します。
- キル効果音は、キルフィードの撃破者が自分（表示名またはキャラクター名が一致）の時だけ鳴らします。音は `SOUNDS.TRIBUTE_AGENT_KNOCKED_OUT`、公式 UI がテイルズ・オブ・トリビュートでカードの体力が 0 になった時に鳴らす音です。「ゲームから除外（破壊）」専用の音は UI のソースにありません。
- フォントは、コンソール UI が既に読み込んでいる面（`$(GAMEPAD_MEDIUM_FONT)`、名前付きは `ZoFontGamepad*`）だけを使い、サイズだけを変えます。`CHAT_FONT` など未読込みの面は、共有メモリ内で新規に作られて PS5 でクラッシュすることが他の PB's アドオンの実測で分かっているため使いません（日本語クライアントの `CHAT_FONT` は大きな CJK フォントです）。
- 設定画面の一覧に出る名前は `PB’s KillLog`（アポストロフィは U+2019）です。LibHarvensAddonSettings のコンソール版は `○○'s △△` の形の名前を「作者名」と「名前」に分けて名前だけを一覧に出すため、ASCII の `'` だと `KILLLOG` になります。アドオン一覧（マニフェスト）側は ASCII の `PB's KillLog` のままです。
- 言語は `GetCVar("language.2")` で判定します。日本語クライアントはこれが `"jp"` を返すため、`"jp"` と `"ja"` のどちらも日本語として扱います。
- 記録は SavedVariables（`PBsKillLog_SavedVars`、アカウント共通）に、日ごとの回数と攻撃・プレイヤーの内訳として保存します。

## テスト

ゲームの外で、ESO の API とライブラリをスタブにして動かすテストです（LuaJIT が必要）。

```bash
luajit test/run.lua
CONSOLE=1 LANGCODE=jp luajit test/run.lua
```

重複抑制、効果音の判定、シロディールと帝都（帝都キャンペーンを含む）で出ること、バトルグラウンドとそれ以外で出ないこと（どちらの場所でも `IsInCyrodiil()` が真・偽のどちらを返しても）、日付の切り替わり（タイムゾーンごと）、キル・死亡・攻撃・プレイヤーの記録、日・月・全期間の集計、階級の境界、設定行の動作（行の作り直し、消去と確認ダイアログ）、ランキングウィンドウの表示と期間切り替え、プレビューがパネルに追従すること（コンソールの「一覧 → パネル」の順序を含む）、日本語表示、危険なフォントが残っていないこと、などを確認します。スタブなので、フォントの生成や描画そのものは確認できません。

## 実機で要確認

1. 「PvP キルフィード」をオフにした状態で、シロディールでウィンドウにログが出ること
2. 帝都でも、シロディールと同じようにログが出て、記録され、効果音が鳴ること（帝都キャンペーンの最中も）。バトルグラウンドでは、ログが出ず、記録もされず、効果音も鳴らないこと。バトルグラウンドからシロディールに戻ると再び出ること
3. 設定画面の一覧に `PB’s KillLog` と出ること、メニューが日本語であること
4. 設定画面を開くとピンクの枠が出て、スライダー・フォントサイズ・レイヤーの変更に追従すること。パネルを閉じる／別のアドオンの設定を開くと消えること
5. HUD に戻ると、枠と同じ場所・大きさ・文字サイズでキルログが出ること
6. 自分がキルした時に効果音が鳴ること
7. キルした／死んだ回数が日別の記録に増えること。日付が変わると新しい日の行になること
8. キルに使った攻撃・死亡の原因になった攻撃が記録されること（取れない場合は「不明な攻撃」になる）。**ここは実機で初めて分かる部分です**: とどめの戦闘イベントが PvP のキルでも出るか、死亡の約 2 秒後に死亡画面の情報が取れるか
9. 日別の記録が 30 行近くあっても、十字キーで最後までスクロールできること
10. ランキングウィンドウが画面の右側に、枠から文字がはみ出さずに収まって出ること。文字が読みやすい大きさであること（大きすぎる／小さすぎる場合は `Ranking.lua` の `FONT_TIERS` と `COLUMN_WIDTH` で調整）。期間の切り替え（全期間・今日・今月）で中身が変わること。設定画面の上に重なって表示され、閉じると消えること
11. 「日別の記録を消去」を押すと確認ダイアログが出て、はいで消え、階級は残ること
