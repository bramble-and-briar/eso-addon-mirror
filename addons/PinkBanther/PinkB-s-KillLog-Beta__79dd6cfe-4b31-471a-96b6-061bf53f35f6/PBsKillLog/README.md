# PB's KillLog

PvP でプレイヤー同士のキルが起きた時に出るキルログだけを、専用ウィンドウに表示する Elder Scrolls Online 用アドオンです。

設定 > ソーシャル の「PvP キルフィード」（チャットへのキルログ出力）が **オフでも** 表示されます。

## 導入

`PBsKillLog` フォルダを ESO のアドオンフォルダに置きます。設定メニューには LibHarvensAddonSettings（20106 以上）が必要です。他の PB's アドオンと同じライブラリで、コンソールでも PC でも使えます。無くてもウィンドウ自体は動作し、`/pbkl` で操作できます。

## 設定（設定 > アドオン > PB’s KillLog）

メニューは日本語クライアントでは日本語、それ以外では英語で表示されます。

| 項目 | 内容 |
| --- | --- |
| ここにプレビューを表示 | 設定画面を開いている間、ウィンドウの場所・大きさ・文字サイズを枠とサンプルのキルで見せる（初期値オン） |
| ウィンドウのロックを解除 | ドラッグで移動、縁のドラッグでサイズ変更。リロード後は必ずロックに戻る。マウスが使える環境のみ（コンソールには出ない） |
| 位置 X / Y | 画面左上からの位置（5 刻み） |
| 幅 / 高さ | ウィンドウサイズ（5 刻み） |
| フォントサイズ | 12〜64 |
| レイヤー（描画ティア） | 低 / 中 / 高。高いほど手前 |
| レイヤー（描画レベル） | 同じティア内の前後関係の微調整（0〜100） |
| 自分がキルした時に効果音を鳴らす | オン/オフ（初期値はオン）。オンにした時に一度鳴らして確認できる |
| テストキルを追加 / ログを消去 | ログの見た目の確認・消去 |

キルログは HUD にしか描かれないため、設定画面からは見えません。そのためプレビューは、ウィンドウとは別のピンクの枠を同じ場所・大きさ・文字サイズで描きます（ChatWindowCustomizer と同じ方式）。スライダーを動かすとその場で追従します。

## スラッシュコマンド

`/pbkl unlock` `/pbkl lock` `/pbkl test` `/pbkl clear` `/pbkl reset` `/pbkl preview` `/pbkl sound [on|off]`

`preview` は設定画面の外（HUD 上）でも枠を出し入れします。HUD では実際のウィンドウの上に重なるので、位置が合っているかの確認に使えます。`sound` は引数なしで切り替えです。

## 仕組み

- `EVENT_PVP_KILL_FEED_DEATH` を直接購読します。「PvP キルフィード」設定の判定は公式チャット側（`chathandlers.lua`）のハンドラ内にあり、このアドオンは判定しません。
- 公式と同じく、ローカル由来とキル地点由来で同じキルが二重に届くため、10 秒以内の重複は 1 行にまとめます。
- 文面・色・ランクアイコンは公式のキルフィードと同じ文字列リソースで生成するため、言語設定に従います。
- キル効果音は、キルフィードの撃破者が自分（表示名またはキャラクター名が一致）の時だけ鳴らします。音は `SOUNDS.TRIBUTE_AGENT_KNOCKED_OUT`、公式 UI がテイルズ・オブ・トリビュートでカードの体力が 0 になった時に鳴らす音です。「ゲームから除外（破壊）」専用の音は UI のソースにありません。
- フォントは、コンソール UI が既に読み込んでいる面（`$(GAMEPAD_MEDIUM_FONT)`）に固定し、サイズだけを変えます。`CHAT_FONT` など未読込みの面は、共有メモリ内で新規に作られて PS5 でクラッシュすることが他の PB's アドオンの実測で分かっているため使いません（日本語クライアントの `CHAT_FONT` は大きな CJK フォントです）。
- 設定画面の一覧に出る名前は `PB’s KillLog`（アポストロフィは U+2019）です。LibHarvensAddonSettings のコンソール版は `○○'s △△` の形の名前を「作者名」と「名前」に分けて名前だけを一覧に出すため、ASCII の `'` だと `KILLLOG` になります。アドオン一覧（マニフェスト）側は ASCII の `PB's KillLog` のままです。
- 言語は `GetCVar("language.2")` で判定します。日本語クライアントはこれが `"jp"` を返すため、`"jp"` と `"ja"` のどちらも日本語として扱います。

## テスト

ゲームの外で、ESO の API とライブラリをスタブにして動かすテストです（LuaJIT が必要）。

```bash
luajit test/run.lua
CONSOLE=1 LANGCODE=jp luajit test/run.lua
```

重複抑制、効果音の判定、設定行の動作、プレビューがパネルに追従すること（コンソールの「一覧 → パネル」の順序を含む）、日本語表示、危険なフォントが残っていないこと、などを確認します。スタブなので、フォントの生成や描画そのものは確認できません。

## 実機で要確認

1. 「PvP キルフィード」をオフにした状態で、シロディール／バトルグラウンドでウィンドウにログが出ること
2. 設定画面の一覧に `PB’s KillLog` と出ること、メニューが日本語であること
3. 設定画面を開くとピンクの枠が出て、スライダー・フォントサイズ・レイヤーの変更に追従すること。パネルを閉じる／別のアドオンの設定を開くと消えること
4. HUD に戻ると、枠と同じ場所・大きさ・文字サイズでキルログが出ること
5. 自分がキルした時に効果音が鳴ること
