# Satuve Xbox UI 1.7.15

- Removed the second visible `Frame Edit Mode` button from Base Options.
- `Move Frames` is now the only settings entry for repositioning interface elements.
- The existing `BUI.Menu.MoveFrames(true)` call remains wrapped by the controller editor, so the same single mode provides the gold selection, D-Pad navigation and movement, A move and place, B exit, pointer dragging, modal settings suppression, and Bandit's normal anchor saving.
- Renamed the bottom keybind from `Exit Frame Edit Mode` to `Exit Move Frames`.
- No frame positioning, Minimap slider, localization, or SavedVariables format was changed.
