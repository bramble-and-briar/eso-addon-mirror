# PB's HudManager

PB製HUDアドオンの設定を、3つのセットにまとめて保存し、まとめて切り替えるESO用アドオン。バージョン 1.4.0。

## 機能

- 導入済みの対象アドオンすべての現在の設定を、名前をつけて **セット1〜3** のいずれかに保存します。
- セットを読み込むと、導入済みの全アドオンへ保存した値を一度に書き込み、**UIをリロード**します。
- 保存は**手動**です。自動では保存されません。保存したあとの変更はそのセットに含まれず、読み込むと最後に保存してからの変更は失われます。
- 設定画面には、導入済みで切り替え対象になっているアドオンだけを表示します。
- 初回起動時に、そのときの設定がセット1「導入時の設定」として保存されます。セット2・3は空です。
- オプションで、**戦闘中にHUDの表示を隠せます**（クエストトラッカー、チャットウィンドウ、ミニマップ、シロディールアラート、時計、Ping・所持品の表示、コンパス）。さらに、**他のアドオンがHUDに出している部品を、一覧から選んで**隠す対象に加えられます。初期状態はオフです。
- 日本語／英語。アカウント共通の設定保存。

### 対象アドオン

| アドオン | フォルダー名 |
| --- | --- |
| PB's ResourceAndSkillBarCustomizer | `PBsConsoleHudCustomizer` |
| PB's Clock | `PBsClock` |
| PB's ChatWindowCustomizer | `PBsChatWindowCustomizer` |
| PB's CyrodiilAlert | `PBsCyrodiilAlert` |
| PB's MiniMap | `PBsMiniMap` |
| PB's NamePlateChanger | `PBsNamePlateChanger` |
| PB's QuestTrackerFontChanger | `PBsQuestTrackerFontChanger` |

対象アドオン側の改修は要りません。各アドオンが公開している設定テーブルを直接読み書きします。

## 導入

配布ZIP内の `PBsHudManager` フォルダーをESOの `live/AddOns` に置きます。
`AddOns/PBsHudManager/PBsHudManager.addon` になる構成です。ソース一式の外側のフォルダーと混同しないでください。

ゲームのアドオン一覧で **PB's HudManager** を有効にしてログイン／UIをリロードします。
対象アドオンより後に読み込まれるよう、マニフェストで対象を `OptionalDependsOn` に指定しています。対象アドオンは未導入でも構いません。

`LibHarvensAddonSettings >= 20106` があれば設定画面に項目が追加されます。ライブラリは任意依存で、同梱していません。未導入でも `/pbhud` コマンドで保存・読み込みができます。

## 使い方

設定画面の **PB's HudManager** に、セットごとに次の行が並びます。

0. **見出し（セクション）** … 「1: 名前」の形で、保存するときにつけた名前を表示します。まだ保存していないセットは「1: （空）」です。セットごとに区切られ、以下の行はその見出しの配下に並びます。見出しの下の最初の行には、保存した日時と保存したアドオンの数を表示します。
1. **このセットの名前** … 保存するときの名前（24文字まで）。触らなければ、そのセットの今の名前のまま保存します。名前欄に入力しただけでは見出しは変わらず、「保存」を押したときに変わります。
2. **現在の設定を保存** … 導入済みの全アドオンの現在の設定をこのセットへ保存します。
3. **このセットを読み込む** … このセットを各アドオンへ書き込み、UIをリロードします。

すでに保存済みのセットへの保存と、読み込みは、**同じボタンをもう一度押したときに実行**します（約10秒以内）。1回目は、何が起きるかを画面上部のメッセージに表示するだけです。空のセットへの保存は1回で実行します。

### 戦闘中にHUDを隠す（オプション）

設定画面の一番下の **オプション** に、次のチェックボックスが並びます。

- **戦闘中にHUDを隠す** … 全体のスイッチです。初期状態はオフで、オフの間は対象のどの表示にも触れません。
- **クエストトラッカー** … 画面右上のトラッカー欄をまとめて隠します（クエストトラッカー、黄金の追跡、ハウス情報など）。ゲームが欄全体を1つの部品として並べ直すため、1つだけを隠すことはしません。
- **チャットウィンドウ** … チャットの発言欄と背景、新着のマークを隠します。チャットの入力欄はそのままなので、戦闘中も入力できます。
- **ミニマップ** … 戦闘中はミニマップをHUDから外します。全体マップを開くことはできます。
- **シロディールアラート** … アラート表示、ログ窓、キャンペーン概況、全体マップのすべて。
- **時計** … 現在時刻・ゲーム内時刻のどちらも。
- **Ping・所持品の表示** … PB's Ping & Bag Space Indicator（`PBsPingAndBagSpaceIndicator`）の表示。このアドオンは戦闘中の非表示だけの対象で、設定のセット（一括切り替え）には含まれません。
- **コンパス** … 画面上部のコンパスとその目印。その下に出るボスの体力バーは、別の部品なので対象外です。

オンにしたものだけが、戦闘が始まると隠れ、戦闘が終わると**持ち主が出したい状態**に戻ります。戦闘が始まる前から隠れていたものは隠れたままで、戦闘中に消えたアラートは戦闘後に復活しません。戦闘中にチェックを変えると、その場で反映します。

この設定は、このアドオン自身のオプションです。セットには含まれず、セットを読み込んでも変わりません。

チャットだけは、チャット全体のコントロールではなく、見える部分（発言欄・背景・新着マーク）を包みます。ゲーム本体のチャットは、隠れている間に入力を始めると、入力欄がフォーカスを取れずに「開いた」状態のまま固まり、以後は開かなくなるためです（オプション→チャット画面を一度開くと直ります）。固まった入力欄が残っていたときは、隠すのをやめた時点で、ゲーム本体の `CloseTextEntry` で閉じます。

仕組みは、対象の部品の `SetHidden` を1つずつ包み、戦闘中は「隠したまま」にしつつ、持ち主の要求は覚えておく、というものです。ミニマップだけは、本体が持つ付け外し（`SetMinimapAttached`）を使います。戦闘が始まるまでは何も包まないので、オフの間はゲームにも他のアドオンにも触れません。包めなかった部品は、戦闘開始で隠し、終了で戻すだけの動作になります（`/pbhud combat` に表示されます）。

### 他のアドオンのHUD部品を選んで隠す

設定画面の **他のアドオンのHUD部品** で、他のアドオンがHUDに出している部品を、戦闘中に隠す対象に加えられます。

1. HUDにいる間に、画面を調べて、見つかった部品の名前を覚えます。ログインの約4秒後と、メニューからHUDに戻るたび（30秒に1回まで）に自動で調べます。
2. **HUDで見つかった部品** のリストから部品を選び、**追加** を押します。
3. 追加した部品は **戦闘中に隠す部品** に並びます。外すには、選んで **外す** を押します。
4. オプションの **他のアドオンの部品** がオンのとき、追加した部品が戦闘中に隠れます。

注意点です。

- **一覧はHUDにいる間に作られます。** 設定画面を開いている間はメニューがHUDを隠すため、そこでは調べられません。ログイン直後は一覧が空のことがあります。HUDに戻ってから開き直してください。**HUDをもう一度調べる** を押すと、次にHUDに戻ったときに調べ直します。
- **見つかるのは、画面に直接置かれた窓だけです。** 別の部品に抱えられた部品は一覧に出ません（例: FancyActionBar+ は、ゲームのアクションバーの子として描くため見つかりません。親を隠すと、ゲームのアクションバーまで隠れます）。
- **どのアドオンの部品かは分かりません。** 名前だけが手がかりです。名前の無い部品や、毎回違う名前で作られる部品は、選んでも次回に同じものを指せません。
- **ゲーム本体の部品（名前が `ZO_` で始まるもの）は、一覧に出ず、追加もできません。**
- 一覧に出ない部品も、名前が分かれば `/pbhud combat add 名前` で追加できます（名前は大文字・小文字を区別します）。追加できる数は20件までです。
- **戦闘で見たいアドオン（バフ表示、ダメージ表示など）を隠さないよう、1つずつ選ぶ形にしています。**
- 隠している間は、その部品自身の画面更新（`OnUpdate`）が止まります。入力を持つ部品は、チャットのときのように状態が崩れることがあります。おかしな動きをする部品は、一覧から外してください。

### 導入していないアドオンの扱い

- 保存したとき導入されていなかったアドオンの設定は、そのセットに入りません。読み込んでも、そのアドオンの設定には触れません。
- いま導入されていないアドオンの設定は、セットに残ります。そのセットへ保存し直しても消えません。あとで導入すると、残っていた設定を読み込めます。

### 保存されないもの

次の値は設定ではないため、保存も上書きもしません。

- 各アドオンが測った画面の実寸（`measured`）
- NamePlateChanger が控えたゲーム標準フォント（`original…`）
- MiniMap の移行済みマーカー・診断ログ・内部フラグ
- Clock の旧版の位置・サイズ項目
- ZO_SavedVars の管理項目（`version`、`$` で始まる項目）

上記以外は、各アドオンの設定テーブルの最上位の項目をそのまま複製します。アドオンに設定が増えても、このアドオンの更新なしで切り替え対象に入ります。

## コマンド

| コマンド | 動作 |
| --- | --- |
| `/pbhud` / `/pbhud list` | セットの一覧と導入済みアドオンを表示 |
| `/pbhud save 1 名前` | セット1へ保存（名前は省略可。省略すると今の名前のまま） |
| `/pbhud load 1` | セット1を読み込み、UIをリロード |
| `/pbhud combat` | 戦闘中の非表示の設定と、いま戦闘中かを表示 |
| `/pbhud combat on` / `off` | 戦闘中の非表示のオン／オフ |
| `/pbhud combat quest off` | 部品ごとのオン／オフ（`quest` `chat` `minimap` `alert` `clock` `ping` `compass` `extra`）。`extra` は、選んだ他のアドオンの部品 |
| `/pbhud combat scan` | HUDを、いますぐ調べる（チャットからなら、HUDが見えている状態で調べられます） |
| `/pbhud combat parts` | 追加した部品と、HUDで見つかった部品を表示 |
| `/pbhud combat add 名前` | 部品を名前で追加（`ZO_` で始まる名前は不可） |
| `/pbhud combat remove 名前` | 追加した部品を外す |

コマンドは確認の2回目を省略して、すぐ実行します。

## 仕組みと注意

- セットは `PBsHudManager_Data`（アカウント共通）に、アドオンごとの設定の複製として保存します。
- 読み込みは、各アドオンの設定テーブルを**同じテーブルのまま**書き換えます。ゲームがUIのリロード時にそのテーブルを保存し、リロード後に各アドオンが新しい値で起動します。そのため、画面上の反映はリロード後です。
- UIをリロードできない環境では、設定は書き込まれたまま「リロードするかログアウトしてください」と表示します。ログアウトやキャラクター選択へ戻るときに保存されます。
- **コンソールで `ReloadUI` を呼べるかは実機で未確認です。** 呼べなかった場合は上記の表示になります。
- **戦闘中の非表示も、実機では未確認です。** 部品ごとに `SetHidden` を包めるかをその場で確かめ、包めなければ「戦闘開始で隠し、終了で戻す」だけの動作に切り替えます。どの部品がそうなったかは `/pbhud combat` で分かります。

## 対象アドオンを増やす

`Core.lua` の `A.targets` に1行足します。`global` はそのアドオンが公開しているグローバルのテーブル名、`store` は保存設定を持つ項目（`sv` または `account`）、`exclude` は設定ではない最上位の項目です。マニフェストの `OptionalDependsOn` にもフォルダー名を足します。

## 変更履歴

- **1.4.0** … 戦闘中に隠す対象に、PB's Ping & Bag Space Indicator の表示を追加。
- **1.3.0** … 他のアドオンがHUDに出している部品を、一覧から選んで、戦闘中に隠す対象に加えられるようにした。HUDを自動で調べて一覧を作る。`/pbhud combat scan` `parts` `add` `remove` を追加。
- **1.2.1** … 戦闘が終わったあと、HUDのチャット欄が入力を受け付けなくなる不具合を修正。戦闘中にチャット全体を隠すと、その間に開始した入力が「開いたまま」固まる（ゲーム本体のソースにも記述がある状態）のが原因だった。チャット全体は隠さず、見える部分だけを隠すように変更。念のため、隠すのをやめたとき、固まった入力欄があれば閉じる処理も追加。
- **1.2.0** … 戦闘中に隠す対象に「コンパス」を追加。
- **1.1.0** … オプションに「戦闘中にHUDを隠す」を追加（クエストトラッカー、チャットウィンドウ、ミニマップ、シロディールアラート、時計を、部品ごとに選べる）。`/pbhud combat` を追加。
- **1.0.2** … 1.0.1 で、設定画面の全項目が先頭の「切り替え対象のアドオン（導入済み）」の配下に入ってしまう不具合を修正。セット見出しを区切り（セクション）に戻し、見出しの文字だけを、つけた名前に追従させるようにした。
- **1.0.1** … 日本語表示で「保存」を押すとUIエラー（`bad argument #4 to 'string.format'`）が出る不具合を修正。メッセージの文字列を、語順に依存しない `{name}` 形式の置き換えに変更。設定画面のセット見出しを、つけた名前の表示に変更。
- **1.0.0** … 初版。

## テストとパッケージ

```
luajit tests/run.lua
python3 scripts/package.py
```

テストはESOのAPIを模したスタブ上で、他のアドオンの部品を選んで隠す機能（画面の調べ方・一覧・追加と削除・戦闘中の非表示・設定画面・コマンド）、戦闘中の非表示（隠す・戻す・持ち主の要求の保持・部品ごとのオン／オフ・ミニマップの付け外し・包めない部品の扱い）、保存・読み込み・除外項目・未導入アドオンの扱い・確認操作・リロード失敗・コマンド・保存データの修復・セット見出し・日英の文字列の置き換えの一致を検証します。さらに、表示しうる全メッセージを日本語・英語の両方で実際に通して、エラーや置き換え漏れがないことを確かめます。
