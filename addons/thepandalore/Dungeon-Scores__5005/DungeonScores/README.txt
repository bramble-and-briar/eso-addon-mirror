Dungeon Scores 0.5.37 (PC beta)
================================

INSTALL
Extract the DungeonScores folder directly into:
    Documents/Elder Scrolls Online/live/AddOns/

Install LibAddonMenu-2.0 r43 or newer separately, then enable Dungeon Scores
in ESO's Add-Ons menu. The optional DungeonScoresRecords folder and companion
are needed only for downloaded community standings and manually requested
score publication. Local scoring does not require a desktop program.
If ESO marks LibAddonMenu-2.0 r43 as out of date, enable "Allow out of date
addons" in ESO's Add-Ons menu. The current library release may require this
even when Dungeon Scores itself targets the current game API.

USE
/ds opens the browser. /ds settings opens settings. /ds freeze captures
completion while keeping scoring open. /ds finalize (or /ds finish) attempts
completion capture and closes the score. /ds reset discards the active run.
/ds report opens the BETA support tab. Browser, Freeze, and Finalize keybinds
are under ESO Controls > Dungeon Scores.

The addon never uploads a run automatically. Publication requires selecting
a finalized score and pressing Send selected score. Give every listed team
member a chance to consent before publishing their ESO @accountname.

For setup, scoring, and privacy details, see the Dungeon Scores ESOUI listing
and the optional companion's PRIVACY.txt. This addon is for PC NA and PC EU.
