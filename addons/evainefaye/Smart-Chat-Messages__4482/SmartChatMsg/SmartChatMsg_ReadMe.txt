SmartChatMsg 3.01
ESO API 101051

Open SmartChatMsg_Help_Guide_v3.01.html for complete offline help.
Required: LibAddonMenu-2.0 >=34 and LibAddonMenuDatePicker.
Open /scm for settings; press Enter to send prepared messages.
Companion: https://scm.perdues.me
Install and run the addon at least once, then exit ESO to write SavedVariables before opening that file in the web editor. Back up files and close ESO before replacing SavedVariables.

Open /scm schedule for the optional resizable Event Planner. /scm keeps the existing settings available. Save changes applies one command/guild draft; Cancel discards edits after confirmation.

The custom planner includes Global settings (default guild/timezone and chat timeout), Guild settings, Advanced scheduling, and Import / Export. The original settings remain optional.
