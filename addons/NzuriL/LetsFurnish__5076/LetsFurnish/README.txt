What it reads and writes
It reads the game's installed files and settings and what the addon saved in the game. It writes your layouts to Documents\LetsFurnish, and its settings, logs, reports and cache to its own folders. In the game's AddOns folder it writes only when you click one of these: Install addon or Update addon, which write the addon's own folder; Send to game, which puts a layout in the folder LetsFurnish_Inbox; Import from game, which tells the game in that folder which recordings have arrived; and Delete, for a layout still waiting in the game, which takes it out of that folder. It never changes the game's installed files. The installed app registers letsfurnish:// links with Windows, for your Windows user only, so that a session link opens it; uninstalling removes that again. If you agree when it asks, it sets Windows' graphics card choice for LetsFurnish itself.

Other players' houses and layouts
The houses and layouts other players create are their work. Record, import and keep only your own houses and layouts, and those whose owner has shared them with you or agreed that you may copy them. Don't copy, save, share or publish another player's house or layout without their permission, including what you see when you visit their house in the game or join a session they host. The addon records a house only for its owner, and in a session the layout stays the host's: guests can keep a copy only if the host allows it.

Playing together
You can plan a house live with other players in a session. The host starts it from one of their layouts, shares its link and chooses who the link lets in: each person once the host or a co-host lets them in, anyone straight in as a viewer, anyone straight in as a decorator, or nobody new. The host and the co-hosts they choose can change that at any time, make a new link so that the old one lets nobody new in, and remove anyone. Everyone in a session sees the house, the layout, each other's display names, cursors and selections, and the messages written there. Hosts and decorators change the layout; viewers watch, write and ping. Share session links only with people you trust, and be kind: you are responsible for what you share and write.

Privacy
LetsFurnish! sends nothing about you anywhere on its own. The installed app asks its update address whether there is a newer version (at start, unless you turn that off in Settings > General, and when you press Check for updates) and downloads one only when you choose. That question names the app's version and carries a random number that the updater, Velopack, made once for this installation and keeps in its folder: it says nothing about you or your PC, Velopack sends it so that an update address could offer a new version to some installations first (ours, a plain store of files, doesn't use it), and uninstalling deletes it. When you start or join a session with other players, the app connects to the LetsFurnish! relay, which passes the session's messages between players. The layout, the names and everything said are encrypted end to end with the key in the session link, so the relay can't read them, and the app never sends that key anywhere. The relay sees who is in the session (as member numbers, with their roles), who joins and leaves, when each message is sent, how large it is and what kind it is (a change, a chat line, a ping), who the link lets in, the app's version, the session's id and the link's invite (never its key), and a device id made for that session alone, so it can't tell that the same PC is in two sessions. Like any server, it sees your IP address: it uses it only to limit how many connections and new sessions one address opens, and doesn't keep it. The key travels in the link, so whoever has the link has the key, also someone later removed or turned away, who still can't get back in. Others see the display name you choose: LetsFurnish! suggests your @account, which you can change before you start or join. While the host is away, the relay stores the session's messages and its layout, still encrypted. It deletes all of a session's data when the session ends: when the host ends it, or once everyone has been gone for seven days (an hour, if nobody but the host ever came in). A problem report is a zip file saved on your computer, which you share yourself. The website has no cookies and no trackers; it remembers that you accepted these terms in your own browser only.
