# 辞書共有 — 1.3.0-dev（実機確認前の検証版）

自分で登録した辞書を、同じグループの指定した相手に渡します。相手もこの共有機能に対応した同じ版を導入する必要があります。内蔵辞書やチャット履歴・その他の設定は送信しません。

通信には、[LibGroupBroadcastの管理表](https://wiki.esoui.com/LibGroupBroadcast_IDs)に登録したプロトコルID **462**・プロトコル名 `PBsTranslateDictionary` を使います（460〜469はPinkBantherのアドオン用に予約）。両者で同じIDと名前が必要なため、公開後は変更しません。1.1.8-dev以前の検証版は開発用の510を使っていたので、それらの版とは共有できません。同じIDを別のアドオンが宣言済みの場合は、共有を初期化せず理由を表示します。

## 必要なもの

- 両者に同じ共有対応版のPB’s Translate。
- 両者に **LibGroupBroadcast** と、その版が要求する依存ライブラリ。LibGroupBroadcast側で辞書共有の通信を有効にします。
- 設定画面の共有欄は **LibHarvensAddonSettings** がある場合に表示されます。無くても `/pbshare` で操作できます。

ライブラリは同梱していません。不足していても通常の翻訳は動作し、共有を選んだ時に利用できない理由を表示します。PS5/Xboxではライブラリと依存先のコンソール対応版の入手・動作確認も必要です。

## 操作

1. 相手と同じグループに入り、戦闘が終わってから、相手に照準を合わせて通常の対人インタラクト操作で放射状メニューを開き、「辞書データを共有」を選びます。設定画面の「共有する相手」で相手を選んで「選んだ相手に辞書を共有」を押すか、チャットで `/pbshare @相手の名前` と入力しても同じです。
2. 件数・宛先・共有する登録内容（先頭5件まで）を確認して「共有する」を選びます。
3. 相手は依頼画面で「受信する」または「辞退する」を選びます。依頼画面を閉じた場合も辞退になります。
4. 受信が完了したら、英語と訳をページごとに確認できます。既存と訳が異なる項目には現在の訳も表示されます。
5. 「取り込み方法を選ぶ」から「新規のみ追加」または「上書きも行う」を選びます。同じ内容の重複は増えません。上書きは追加の確認画面を経て、競合項目をまとめて受信した訳に変更します。

受信後に閉じても辞書は自動で変わりません。設定の「受信した辞書を確認」から再開できます。受信データ・転送途中のデータはメモリ内だけに保持し、UI再読み込みやログアウトでは破棄します。取り込み済みの辞書と、直前の取り込み前バックアップはSavedVariablesに保存します。

「取り込み前の辞書に戻す」で復元できます。ただし、取り込み後に行った手動登録も元に戻ります。バックアップは直近1回分です。取り込み時は最新の辞書と結合するため、内容確認中の手動登録は維持されます（上書きを選んだ競合項目を除く）。

照準先の放射状メニューには、標準の「取引」項目の後に「辞書データを共有」を追加します。追加は項目を並べる処理（`AddMenuEntry`）の直後に行い、メニューを組み立てる本体（`ShowPlayerInteractMenu`）には割り込みません。本体に割り込んだ1.1.1-devではコンソールでprivate関数エラーが出ました。現在の方式はPS5で問題なく動作しています。取引ができない相手（無視中・通信制限あり）には表示しません。

チャット・グループ・フレンド・ギルド名簿のソーシャルメニューには項目を追加しません。「共有する相手」の一覧には、同じグループのオンラインの相手（自分以外）が表示されます。

## コマンドと設定

| 操作 | 内容 |
| --- | --- |
| `/pbshare @相手の名前` | 共有確認画面を開く。相手は同じグループのオンラインメンバー |
| `/pbshare` / `/pbshare status` | 転送状況。取り込み待ちの場合は内容確認 |
| `/pbshare review` | 受信辞書の内容確認 |
| `/pbshare cancel` | 転送を中止、取り込み待ちデータを破棄 |
| `/pbshare restore` | 直前の取り込み前へ戻す確認画面 |
| `/pbshare accept` | 現在の受信依頼を承諾する補助コマンド |

設定画面で「辞書の共有依頼を受け付ける」をオフにできます。無視リストの相手のデータは受け付けません。

## 転送の仕様と制約

- 1回200件・16,384バイトまで。英語キーは80バイト、訳（品詞指定を含む）は240バイトまで。超過・不正な登録があると、部分送信せず説明を表示します。
- 制御文字、ESOの `|` マークアップ、不正なUTF-8、不正な品詞・活用指定は受け付けません。受信文字列をLuaとして実行しません。
- 80バイトずつ送り、相手の確認応答を受けて次へ進みます。30秒応答がなければ最大3回再送します。受信側は150秒無通信、転送全体は1時間で打ち切ります。
- 通信はLibGroupBroadcastを通し、他アドオンと帯域を共有します。大量の辞書には数分以上かかる場合があります。戦闘中の通信はライブラリ側の扱いに従って延期され、長く続くとタイムアウトします。
- グループ離脱・破損・件数不一致では取り込み待ちに進みません。受信完了まで辞書へ一切書き込みません。
- LibGroupBroadcastは**グループ全体への配信**です。宛先識別で指定した相手のアドオンだけが受信処理・取り込みを行いますが、秘密の個人通信や暗号化ではありません。
- 整合性検査はAdler32です。改ざんに対する暗号学的な保証ではありません。受信元はライブラリから渡された実際のグループユニットから解決し、転送途中の送信者変更を受け付けません。
- 送信者の「転送完了」は相手への到着を示し、相手が取り込んだことを示す通知ではありません。
- 同時に進める共有は1件です。受信辞書が取り込み待ちの間も、次の共有を受け付けません。

## 検証

```sh
lua test/run.lua
lua test/accuracy.lua
lua test/outgoing.lua
lua test/dict_check.lua
lua test/sharing.lua
lua test/sharing_ui.lua
lua test/sharing_interact.lua
```

Lua 5.4 / LuaJITで、送受信47件・UI結合71件・放射状メニュー21件の検証を追加（登録ID・プロトコル名、設定画面からの開始、ソーシャルメニューとメニュー本体に割り込まないことを含む）。通信は非同期のキューで2人を模擬し、ロス、最終確認応答のロス、辞退、離脱、タイムアウト、改ざん、宛先違い、UTF-8の分割を検証しています。UIは公開APIに合わせたテスト用実装です。既存の翻訳例360件、精度検証136件、チャット表示・送信翻訳・辞書検査も確認します。

**ゲーム内での送受信・画面表示はまだ検証していません。** 公開配布の前に、2台で次を確認してください。

1. 両者がライブラリ導入済みで、同じグループ・非戦闘状態。放射状メニュー、設定画面の「共有する相手」＋ボタン、`/pbshare @名前` のそれぞれから共有確認が開く。
2. 依頼の辞退・画面を閉じる操作で転送されない。
3. 新規語、同内容、異なる訳を各1件入れて、内容確認・新規のみ追加・上書き・復元を確認。
4. 100件程度の辞書でページ表示・転送状況・他アドオンとの帯域共存を確認。
5. 途中の離脱・UI再読み込みで辞書の部分書き込みがない。
6. PS5/Xboxで確認ダイアログの操作・文字収まりを確認。
