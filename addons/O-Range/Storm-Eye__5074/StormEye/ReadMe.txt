# StormEye

A polished custom reticle for **The Elder Scrolls Online**.

StormEye replaces the default reticle with a smooth, animated version of the **in-game Sorcerer crosshair icon**, featuring lightning effects, stealth scaling, enemy pulse, and complete color + opacity control.

---

## Features

- Based on the official in-game **Sorcerer custom crosshair** icon
- Smooth size, rotation, and opacity transitions
- Adjustable lightning flash intensity
- Optional lightning while targeting enemies
- Stealth mode with customizable scale and color
- Enemy targeting with custom color, pulse strength, and optional lock rotation
- Independent opacity sliders for Idle / Stealth / Enemy
- Full RGB color pickers for all three states
- Hide in First Person option
- One-click Reset Colors & Opacities button
- Automatically hides in most UI menus
- Fully configurable via LibAddonMenu-2.0

---

## Requirements

- **LibAddonMenu-2.0** (version 43 or higher)

---

## Installation

1. Download the addon
2. Extract the `StormEye` folder into:
   - `Documents\Elder Scrolls Online\live\AddOns\`
3. Enable **StormEye** in the in-game Add-On menu
4. Type `/reloadui` or restart the game

---

## Settings

Go to **Settings → Addons → StormEye**

You can customize:

**General**
- Enable / Disable
- Reticle Size
- Enemy Coloring
- Lock Rotation
- Hide in First Person
- Lightning on Enemies

**Effects**
- Lightning Intensity
- Stealth Scale
- Enemy Pulse Strength

**Opacity**
- Idle Opacity
- Stealth Opacity
- Enemy Opacity

**Colors**
- Idle Color
- Stealth Color
- Enemy Color

+ Reset Colors & Opacities button
