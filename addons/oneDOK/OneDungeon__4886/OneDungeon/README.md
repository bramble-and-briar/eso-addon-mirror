# OneDungeon 26.1

Автор: oneDOK.

Скопируйте эту папку в `Documents\Elder Scrolls Online\live\AddOns`.
Поддерживается клавиатурный Dungeon Finder → Specific Dungeons, API 101051.

LibSets и LibUndauntedPledges больше не нужны: справочник достижений/заданий и расчёт обетов встроены. При обновлении замените файлы OneDungeon и выполните `/reloadui`. На время первой проверки отключите MyDung и другие модификаторы этого списка. Если библиотеки нужны другим аддонам, оставьте их установленными.

N/V выбирают реальные обычную/ветеранскую активности независимо друг от друга.
Белый значок означает незавершённое сюжетное задание.
Синий значок означает сегодняшний обет; свечение означает принятый обет.
Иконки: яркая — выполнено, тусклая — не выполнено, — — нет достижения, ? — неизвестно. Наведите курсор для подробностей.

Команды: `/onedungeon debug`, `/onedungeon dump`, `/onedungeon refresh`.
При ошибке интеграции возвращается стандартный список до `/reloadui`.

В 0.2.1 исправлены привязки и высота поля названия. 78 локальных тестов пройдены; отрисовку и очередь нужно проверить в ESO. Gamepad не изменяется. Встроенные данные покрывают 58 подземелий; неразрешённые записи показывают ?. Для составного HM требуются все достижения боссов, из встроенного справочника.

Расписание проверено для API 101045–101051. Новый API требует обновления справочника, иначе «Сегодня» остаётся неизвестным. Время сброса берётся из ESO; открытый список обновляется автоматически при сбросе. Активные обеты определяются отдельно по журналу.

Изменения интерфейса 0.2.1: Quest показывает белый значок незавершённой истории, синий значок сегодняшнего обета и синий со свечением для принятого обета. Подсказка Quest — только легенда. Подсказок названий нет. Для достижений используется штатная подсказка ESO; для неизвестных/отсутствующих сохранена прежняя. Заголовки: Vet, HM, Tri. Для составного HM штатная подсказка относится к первому невыполненному достижению (первому в списке, если все выполнены).
