Book-location data attribution
==============================

LorebookLocations.lua adapts map records contributed to UESP Gamemap.
Source: https://gamemap.uesp.net/?game=eso
Read-only data endpoint: https://gamemap.uesp.net/db/gamemap.php
Snapshot: 2026-10-31. Book records from zone, city, dungeon and interior maps.

Credit: UESP and the UESP Gamemap community contributors.
UESP content licensing: https://en.uesp.net/wiki/UESPWiki:Copyright_and_Ownership
Creative Commons Attribution-ShareAlike 2.5:
https://creativecommons.org/licenses/by-sa/2.5/
https://creativecommons.org/licenses/by-sa/2.5/legalcode

Changes made for this data file: selected book records, normalized and rounded
map coordinates, grouped by book title and collection, shortened location notes,
and converted the records to a compact Lua table. Later batches append
dungeon, public-dungeon and quest-interior records through the remaining eligible maps,
while preserving earlier records and order.
These adaptations to the data
are distributed under the same CC BY-SA 2.5 license.

For uniquely named books, collection labels are also checked against UESP's
game-extracted Update 51 catalogue (2026-10-09):
https://github.com/uesp/uesp-esolog/blob/master/esoBookCollectionData.php

Book titles and other original game content belong to ZeniMax Online Studios.
No book bodies or map images are included. No data from the separate LoreBooks
add-on is included. This notice concerns the location-data file, not authorship
of the Tamriel Collections add-on. The add-on author remains MajesticMinxi.

--------------------------------------------------

contributors, under the same CC BY-SA 2.5 license above. Changes: extracted
location/quest metadata, removed wiki markup, shortened display text, matched
book IDs and verified linked map coordinates. No book bodies are included.
The map hints adapt names and parent relationships from the same UESP Gamemap.

Zone and coordinate conversion update (2026-11-01)
------------------------------------------------
The UESP map grid includes power-of-two tile padding. Native positions are
converted using each map's actual tile counts and parent relationship.
This conversion affects all non-power-of-two map grids. Map-grid source facts
remain intact; the conversion is performed when a point is displayed.
Conversion reference: https://github.com/uesp/uesp-esolog/blob/master/createMapLocations.php
Book-specific location clarification:
https://en.uesp.net/wiki/Online:The_All-Beneficent_King_Fahara%27jad
https://en.uesp.net/wiki/Online:Cloudy_Dregs_Inn
Location filter metadata adapts named location links from the same credited
Game Book source pages. No book bodies are included.

Overworld zone filter grouping update (2026-11-01)
------------------------------------------------
Only the 48 published Overworld Zones are location chooser entries.
Cities, delves and interiors inherit their closest named zone; quest instances
without a geographical parent use verified entry zones where available.
This changes filter membership only; source floor maps and XY remain intact.
