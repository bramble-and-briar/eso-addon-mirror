Ramaladni — Changelog

v1.0.1-Stable — 2026-11-27

Class Mastery & HUD
- Automatically detect purchased Class Mastery passives on eligible builds; support all 35 passives across the seven classes.
- Update mastery indicators automatically when the committed build changes; remove inactive mastery indicators without affecting ordinary effects.
- New mastery icons appear near the screen center; remember dragged positions by passive key. Masteries no longer consume the 12 regular-effect slots.
- Share the Spoils: remove the idle xN proc counter from the HUD while retaining personal/group ultimate values, the green activation flash and cooldown display.

Buff/Debuff Search
- Strictly separate BUFF (41) and DEBUFF (33) results, including numeric ID searches.
- Use the classified MD-ESO catalog and grouped effect IDs; exclude unclassified IDs and runtime discoveries from new selections.
- Preserve existing saved indicators. Update the Buff/Debuff Base link.

Saved Settings & Fixes
- Separate EU, NA and PTS SavedVariables, with one-time migration of legacy shared settings and protection of existing world profiles.
- Preserve ordinary effect positions and character profiles; retain legacy data for recovery where applicable.
- Fix player-buff/enemy-debuff routing when IDs or names match.
- Correct Nightblade critical-stat API calls and Arcanist combat callback argument positions (Rigor ability ID and Ink overflow).

Technical Cleanup & Performance
- Consolidate addon modules under one global namespace, localize API references and register runtime events/commands through addon initialization.
- Replace legacy power-type aliases, remove undocumented GetUnitId calls, redundant API existence checks and unreachable fallbacks; remove unused Combo helper and obsolete discovery-cache accumulation.
- Use native ability-ID event filters with dynamic registration and removal; retain a single compatibility subscription when name-dependent matching is required or an ID filter is rejected.
- Enable class event groups only when needed by the current masteries; retain shared dependencies and preserve state for masteries that remain active.
- Filter applicable incoming-damage results and Sorcerer shield target tags while preserving existing effect matching behavior.
- Retain the 200 ms HUD scan cadence, the existing effect catalog and the dependency-free design.
- Update AI disclosure, credits and release documentation in response to ESOUI feedback.

Validation: automated regression and registration/dispatch stress tests in a simulated ESO API environment. Full final in-game regression, PTS runtime validation and actual engine CPU/memory profiling remain outstanding. Group Stats is not included in this release.

v1.0.0 STABLE — 2026-11-04
- First public stable release, based on the user-tested v1.0.4g RC5.
- Search buffs and debuffs by Russian/English names or Ability ID.
- Click-to-add effects, automatic icons and grouped effect IDs.
- Tracking of Major/Minor effects, eight combat statuses and select special
  effects; separate Class Mastery trackers for all seven classes.
- Movable HUD indicators, independent timers and cleanup when removing items.
- Hide indicators in standard ESO menus; restore on returning to gameplay.
- Updated settings layout, original MD logo, community and Discord links.
- No external addon library dependencies.
- Release metadata and documentation updated; combat logic unchanged from RC5.

Earlier builds v1.0.4a through v1.0.4g were internal release-candidate
iterations. The experimental v1.0.5 catalog was not adopted.
