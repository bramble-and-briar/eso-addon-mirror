# Fury's Addons Menu changelog

## 1.3.2
- Its saved settings now load the standard way (ZO_SavedVars), as ESOUI's reviewers asked. They are moved over by themselves the first time you log in, so nothing changes for you.

## 1.3.1
- Fury's addons now require this library (it used to be optional), so it shows in the game's Required Add-Ons list. No change to how it works.

## 1.3.0
- **The Fury sidebar lives here now.** The sidebar, the `/fury` addons list and the title-bar icons used to be built by the Fury addons themselves, from a copy inside each one. That code now lives only in this library, and each Fury addon just puts itself on its list. Nothing changes on screen, and your sidebar settings and key carry over.

## 1.2.0
- **Its own download.** Fury's Addons Menu is now a library of its own on ESOUI and in Minion, instead of a folder inside every Fury addon. Fury's addons list it as an optional library. Your sidebar settings and your key carry over.

## 1.1.0
- The sidebar's settings (shown, place, row or column, size, locked, hidden in combat) are saved here, one set for the whole PC.

## 1.0.0
- One key for the Fury sidebar, "Show or hide the Fury sidebar", under Fury's Addons in Controls > Keybindings.
