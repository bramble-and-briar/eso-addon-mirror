# TTC Motif Prices 0.4.2 — публикационная версия

Автор: **TjeEmpejoj**. Код создавался с помощью ChatGPT/Codex. Английская инструкция и обязательное уведомление ZeniMax — README.txt.

Показывает средние цены TTC и блок Source / Источник в подсказках коллекционных стилей для клавиатуры и мыши. Зависимости: Tamriel Trade Centre и LibCharacterKnowledge >= 301020.

## Что изменено

- Только место, способ и условия получения. Художественные описания, внешний вид и несвязанные достижения в блок аддона не выводятся.
- Источник показывается независимо от наличия цены TTC и возможности продажи предмета.
- Встроенный каталог привязан к конкретным collectible ID. Броня, оружие, маски и наплечники могут иметь разные источники.
- Указаны серии кронных ящиков, названия магазинных наборов, событийные контейнеры и игровые награды. Временный источник не означает, что он доступен прямо сейчас.
- Исправлены некоторые неточные игровые описания: Glass, Ancient Orc, Outlaw и Assassins League. Для Dremora указаны соответствующие главы типы Dremora Plunder Skull.
- Убраны подсказки о невозможности перекраски и скрытии убранного оружия: они не являются способом получения.

## Покрытие и ограничения

Проверена выгрузка ESO API 101051, язык en, от 18 ноября 2026 года: 8253 отдельных коллекционных предмета. Из них 7 — служебные команды скрытия экипировки.

| Основание записи | Количество |
|---|---:|
| Сведения о получении из ESO | 6118 |
| Дополненные / исправленные источники | 1987 |
| Источник не подтверждён | 141 |
| Служебные команды | 7 |

Наличие записи не гарантирует, что предмет сейчас продаётся или выпадает. Часть записей каталога может относиться к скрытым, устаревшим или ещё не выпущенным вариантам. Состав наборов и награды событий могут меняться. Старые способы получения подписаны как исторические; для неподтверждённых записей выводится «Источник получения пока не подтверждён».

6118 игровых записей содержат сведения о получении, но не все прошли независимую фактическую сверку. Дополнительная база использует ESO Hub, официальные списки наград ZOS, официальную поддержку, руководства Tianlein и опубликованные сведения о магазинных предложениях. SOURCE_REFERENCES.txt содержит ID, название, текст, основание записи и ссылки. Количество относится к отдельным частям и вариантам, а не к семействам стилей.

Дополнения переведены на русский; извлечённые из английской выгрузки игровые сведения пока остаются на английском. Другие языки используют английский текст. Имена стилей не используются для поиска источника во время игры: все соответствия закреплены по ID.

## Команды

- `/ttcmp audit` — выгрузить все доступные через API стили с источниками и их основанием. Затем `/reloadui` сохраняет отчёт в live/SavedVariables/TTC_Motif_Prices.lua.
- `acquisitionAudit.missingSources` — ID без подтверждённого источника. Это отличается от старого missing, который проверял отсутствие любого текста.
- `acquisitionAudit.sourceCounts` — отдельные счётчики native, researched, unconfirmed и control.
- `/ttcmp diag`, `/ttcmp hover`, `/ttcmp styles`, `/ttcmp style <ID>` — диагностика цен и распознавания.
- `/ttcmp buy [book]` — открыть поиск TTC для стиля под курсором или полной книги. ESO может запросить подтверждение открытия ссылки.

Отчёт не записывает изученность, имена персонажей или данные аккаунта. Новый запуск audit заменяет предыдущий отчёт. Сам аддон не меняет изученность, инвентарь или настройки торговли.

Проверены цены, привязанные книги и главы, отдельные страницы, обработчик наведения, русский интерфейс, отсутствие описаний внешнего вида, неизвестные ID и источники для разных частей одного стиля. Проверка реального отображения версии 0.4.0 в ESO остаётся необходимой.
