KelaPadUI Enhanced changelog (newest first)

Version numbers before 2.5.0 were assigned retrospectively to the dated
changelog entries; they do not imply those versions were released. Future
entries use major.minor.patch and match the add-on manifest version.

2.8.0 - 11/11/2026
- Renamed the add-on to KelaPadUI Enhanced and moved it to its own folder and manifest, so add-on managers no longer treat it as the abandoned original KelaPadUI. Delete the old KelaPadUI folder, and the KelaPadUIBuyingData and KelaPadUIListingData folders if present, before installing. Settings and trading history are preserved.
- The add-on now stays disabled while the original KelaPadUI is loaded and shows a gamepad dialog explaining how to fix it, instead of letting both copies share one settings file.
- Accepting a duel or a ready check no longer fails with "Attempt to access a private function 'CancelTaskbarWindowFlash' from insecure code". The Battleground round paging no longer hooks the keybind dispatcher; the L2/R2 bindings are ethereal entries on both scoreboard scenes instead, so the recap looks unchanged.
- Leaving the settings menu shows the reload prompt again when a reload-gated setting changed. The check iterated a table by array index instead of by key, so it never found a setting.
- The KelaPadUI Enhanced submenu now shows a header with the add-on name above its first visible entry.
- Added a packaging script that builds the ESOUI upload zip, and GitHub Actions that audit, package, and publish tagged releases to ESOUI.

2.7.0 - 11/10/2026
- Added German, French, and Russian interface translations, along with a translation script to convert to other languages; the add-on loads the matching client-language file automatically and falls back to English for other languages.

2.6.1 - 11/10/2026
- Added a Base game fixes option that restores L2/R2 battle-round paging on the Battleground scoreboard.
- Fixed the 6v6v6 and 9v9 scoreboard team panels overlapping their player rows.
- Fixed the Activity Finder's Battleground entry staying locked until the screen was closed and reopened.
- The fixes mirror upcoming official ones and are reload-gated; turn the option off, or delete kpui_basegame_fixes.lua from the manifest, after ZOS ships them.

2.6.0 - 11/05/2026
- Unified Antiquity filters under Additional gamepad filters, adding name search, multi-select difficulty and progress filters, and a clear option.
- Filter changes now apply immediately; dialogs use Back, show named color-coded qualities, and include the game's available filter choices.
- Provisioning and furnishing ingredient, skill, and quest filters now stay in sync with the game's own filter dialog and persist with it.
- Replaced the provisioning recipe Level 1 / CP 1 filter with Unique Dishes, which shows Delicacies.

2.5.0 - 11/04/2026
- Added session-persistent gamepad achievement search and completion, in-progress, and tracked filters; unified the filter shortcut across Antiquities and the supported additional filter screens.
- Fixed the recipe filter shortcut disappearing after closing its dialog or conflicting with the crafting advisor.
- Added gamepad recipe name, quality, and level filters for provisioning, and name and quality filters for furnishing plans at crafting stations.
- Added set-name search to gamepad Item Set Collections and the transmute station's reconstruction screen, controlled by one Additional gamepad filters setting.
- Fixed the dashboard's initial skill-point count when USPF starts before skyshard data is ready; the row now uses live point allocations and refreshed skyshard totals.
- Added Rumours and an Events section with Tome Challenges, PVP Veterancy, and Golden Pursuit to Quick Access.
- Added a gamepad Trait Research browser with a full matrix, per-character progress, item availability, and active research countdowns. LibCharacterKnowledge enables other characters on the current server; without it, the current character is still available.
- Added dashboard research progress and PVP Veterancy, plus live Golden Pursuit, Tamriel Tomes, and event countdowns.
- Improved companion details in Collections, including level, rapport, passive perk, and equipped gear, and added Companions to Quick Access.
- Fixed Quick Access disappearing during background updates and interfering with gamepad dialogs.
- Fixed guild selection reverting after listing an item with ATT and corrected Sets browser registration.

2.4.0 - 10/28/2026
- Added an optional PS5 button map setting, off by default, so controller hints can use PlayStation 5 icons without a reload.
- The dashboard's Events section now lists additional active promotional campaigns alongside Golden Pursuit and Tamriel Tomes.
- Campaigns are sorted by time remaining, and extra campaigns are shown as a +N count on the last row.
- The Events section stays visible when only a promotional campaign is running.
- Removed the empty Announcements block, because the client no longer publishes that data to add-ons.

2.3.1 - 10/27/2026
- Fixed dashboard value colors, including a refresh bug that dropped the color from rows returning text and color.
- Pledge statuses, maxed character values, and capacity now use the intended blue, teal, green, orange, and red colors.
- Random Dungeon and Battleground are green for both Ready and Complete.
- Populated the dashboard on player activation so the first main-menu open already shows data.
- Fixed the daily tracker wiping itself when the reset timer wobbled by one second.
- Daily state now stores an absolute reset boundary that clears only after it has passed.
- Reset boundaries are snapped to five minutes, and the reset time is learned from the first valid timer.
- The writ, archive, and pledge rows share one clock reading and boundary per refresh.

2.3.0 - 10/26/2026
- Extended per-character daily tracking to Infinite Archive and Undaunted pledges.
- All three daily rows now use one journal scan, with turn-ins recorded from quest removal.
- The pledge total counts only completed pledges, and its sub-rows show Ready, Active, Turn In, or Complete.
- Added a Daily reset countdown row and extra space before each dashboard section.
- Random Dungeon and Battleground now show exactly Ready or Complete.
- Renamed Daily undaunted to Undaunted Pledges.
- Fixed the crafting-writ counter so it no longer counts the permanent completed-quest archive.
- Writs now combine finished journal quests with per-character turn-ins for the current reset day.

2.2.0 - 10/23/2026

- Daily writ and Infinite Archive counts now include handed-in quests instead of dropping to zero.
- Random Dungeon and Battleground now use the reward cooldown APIs.
- Added pledge sub-rows with giver, dungeon, and status, and added dashboard scrolling.
- Added the main-menu Quick Access panel and the KELAPAD dashboard.
- The dashboard fills once when the gamepad main menu is first opened instead of refreshing every five seconds.
- Fixed dashboard layout, completion colors, and the Quick Access header error after in-game testing.
- Removed dead trading confirmation-dialog hooks that broke Activity Finder dialog buttons.
- Trading buy and listing history decoration remains inactive until it can be restored through a dialog-owned path.
- Added a reload-required prompt for reload-gated settings.
- PersonalAssistant junk marking now defaults on when installed and works in gamepad mode.
