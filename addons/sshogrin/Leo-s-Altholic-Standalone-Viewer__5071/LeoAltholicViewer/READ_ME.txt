This is a standalone viewer for Leo's Altholic addon for ESO.
Your SavedVariables file location should be in the standard location for ESO addon SavedVariables, which will be in either:
"OneDrive/Documents\Elder Scrolls Online\live\SavedVariables\" 
or 
"Documents\Elder Scrolls Online\live\SavedVariables\"

When you first launch the app, Windows SmartScreen may show a blue 'Windows protected your PC' warning because this is an independent, unsigned tool. Click More info and then Run anyway to start it.
