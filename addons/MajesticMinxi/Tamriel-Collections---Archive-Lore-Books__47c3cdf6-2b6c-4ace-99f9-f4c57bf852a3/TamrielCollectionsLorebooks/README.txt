Tamriel Collections - Archive Lorebooks
Version: 1.0.0
Author: MajesticMinxi

Browse ESO's native Lore Library and correspondence with read status, search,
an incomplete-family filter, acquisition directions and supported map targets.
Crafting motifs and style pages belong to their separate Collections modules.
No separate core or other module is required.

Controls: X opens the book list or reads a collected book. Circle returns.
L3 switches between incomplete and all families. R3 chooses a main map zone.
Square opens the selected book's map where a supported target is available.

Changes in 1.0.0:
- Going up from an interior book map centers on its dungeon, delve or city
  entrance when ESO supplies a matching marker on the surrounding map.

Install this complete folder as the replacement for the previous version,
then Reload UI. The add-on version should read 1.0.0.
