ALTHI optional language pack: es
Install only if you want this interface language in addition to English and your ESO client language.
Extract this folder beside ALTHI under live/AddOns, enable it and reload.
The main ALTHI addon is needed to use the interface. This pack contains translation data only.
Generated/revised with AI assistance; German is complete, other non-English language packs are translation drafts.
