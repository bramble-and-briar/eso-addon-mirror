# Чек-лист тестирования GroupModerationBlacklist

## Подготовка

- [ ] Установить аддон в `Documents/Elder Scrolls Online/live/AddOns/`
- [ ] Установить LibAddonMenu-2.0 (опционально)
- [ ] Перезапустить игру или выполнить `/reloadui`
- [ ] Открыть меню группы и проверить наличие вкладки «Черный список»

## Тестирование чёрного списка

### Добавление аккаунта
- [ ] Открыть вкладку «Черный список»
- [ ] Ввести `@testaccount` в поле ввода
- [ ] Нажать «Добавить»
- [ ] Проверить, что аккаунт появился в списке
- [ ] Проверить, что поле ввода очистилось
- [ ] Проверить, что дата добавления отображается

### Удаление аккаунта
- [ ] Навести курсор на запись в списке
- [ ] Проверить, что появилась кнопка удаления
- [ ] Нажать кнопку удаления
- [ ] Проверить, что запись удалена из списка
- [ ] Проверить, что запись удалена из SavedVariables (через `/reloadui` и повторную проверку)

### Валидация формата
- [ ] Попробовать ввести аккаунт без `@` — должно появиться сообщение об ошибке
- [ ] Попробовать ввести аккаунт с недопустимыми символами — должно появиться сообщение об ошибке
- [ ] Попробовать ввести пустую строку — должно появиться сообщение об ошибке

## Тестирование автоматического исключения

### Базовый сценарий
- [ ] Добавить тестовый аккаунт в чёрный список
- [ ] Стать лидером группы
- [ ] Попросить тестового игрока войти в группу
- [ ] Проверить, что игрок автоматически исключён
- [ ] Проверить сообщение в чате: `[Moderation] Исключение участника: @account`

### Проверки безопасности
- [ ] Проверить, что не-лидер не может исключить игрока
- [ ] Проверить, что игрок не может исключить сам себя
- [ ] Проверить throttle: при быстром входе нескольких игроков из списка исключается только первый (в течение 5 секунд)

### Отладочные сообщения
- [ ] Проверить появление сообщений `[Moderation]` в чате при входе каждого участника
- [ ] Проверить появление сообщений `[Moderation]` при пропуске (не лидер, не в списке, throttle)

## Тестирование перевыставления в Activity Finder

### Сценарий с финальным участником
- [ ] Создать группу и выставить её в Activity Finder
- [ ] Добавить тестовый аккаунт в чёрный список
- [ ] Заполнить группу до максимума (чтобы тестовый игрок был финальным)
- [ ] Попросить тестового игрока войти в группу
- [ ] Проверить, что игрок исключён
- [ ] Проверить, что группа автоматически перевыставлена в Activity Finder
- [ ] Проверить сообщение `[GroupActivity] KickConfirmed`

### Сценарий без финального участника
- [ ] Создать группу и выставить её в Activity Finder
- [ ] Добавить тестовый аккаунт в чёрный список
- [ ] Заполнить группу частично (чтобы после кика остались участники)
- [ ] Попросить тестового игрока войти в группу
- [ ] Проверить, что игрок исключён
- [ ] Проверить, что группа НЕ перевыставлена (так как она не была полной)

### Проверки безопасности перевыставления
- [ ] Проверить, что перевыставление не происходит, если лидер сменился
- [ ] Проверить, что перевыставление не происходит, если группа распущена
- [ ] Проверить, что перевыставление не происходит, если группа не в Activity Finder

## Тестирование SavedVariables

- [ ] Проверить создание `GroupModerationBlacklistSV` после первого запуска
- [ ] Проверить сохранение чёрного списка между сессиями
- [ ] Проверить сохранение снимка параметров группы
- [ ] Проверить сброс флагов при смене лидера

## Тестирование в бою (опционально)

- [ ] Проверить корректную работу аддона во время боя
- [ ] Проверить, что защищённые вызовы работают через `CallSecureFunction`
- [ ] Проверить отсутствие ошибок в чате

## Известные ограничения

- Точные названия функций Activity Finder (`GroupActivitySetData`) могут отличаться в зависимости от версии API. Если перевыставление не работает, проверьте консоль на наличие ошибок и верифицируйте функцию в исходниках игры.
- Для тестирования перевыставления необходима группа в Activity Finder.

## Отладка

Все отладочные сообщения выводятся в чат с префиксом `[Moderation]` или `[GroupActivity]`. Для отключения отладки удалите вызовы `d()` из файлов.
