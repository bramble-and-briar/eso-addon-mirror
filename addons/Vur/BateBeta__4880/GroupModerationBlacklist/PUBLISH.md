## Описание

Аддон для модерации группы в The Elder Scrolls Online. Позволяет лидеру группы вести чёрный список аккаунтов и автоматически исключать их при входе в группу.

### Основные функции

- **Вкладка «Черный список»** в меню группы — удобный интерфейс для управления списком
- **Автоматическое исключение** — при входе участника из списка он автоматически исключается лидером
- **Перевыставление в Activity Finder** — после исключения финального участника группа автоматически перевыставляется
- **Панель настроек** — гибкая настройка поведения аддона через LibAddonMenu-2.0

### Как использовать

1. Откройте меню группы (по умолчанию `G`)
2. Перейдите на вкладку «Черный список»
3. Введите аккаунт формата `@accountName` и нажмите «Добавить»
4. При входе этого аккаунта в группу он будет автоматически исключён

### Настройки

- **Включить автоматическое исключение** — включить/отключить автоисключение
- **Задержка между исключениями** — минимальное время между киками (1-30 сек)
- **Включить перевыставление** — включить/отключить автоперевыставление в Activity Finder
- **Режим отладки** — вывод отладочных сообщений в чат

### Совместимость

- **ESO API:** 101045
- **Платформы:** Windows, Mac, Xbox, PlayStation
- **LibAddonMenu-2.0:** опционально (для панели настроек)

### Известные ограничения

- Точное название функции `GroupActivitySetData` может отличаться в зависимости от версии API. Если перевыставление не работает, проверьте консоль на наличие ошибок.
- Для тестирования перевыставления необходима группа в Activity Finder.
