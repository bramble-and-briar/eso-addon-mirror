# Yudo's Kill Feed
**Author:** YudoAn
**License:** Artistic-2.0
**Version:** 1.3.5

## Description
Yudo's Kill Feed is a utility addon for The Elder Scrolls Online. It acts as a "Gatekeeper" for the native PvP Kill Feed, filtering strictly on the events that matter to you to avoid spam.

## Features
- **Focused Filtering:** Choose between Player, Group or Guild filter modes.
- **Event toggles:** Choose if you want to see Kills, Deaths or both.
- **Vanilla Integration:** Filters the native game notifications without adding custom text, icons, or other modifications.
- **Native Localization:** Compatible with all game languages, as it preserves and filters the original ZOS notification text.
- **Zero-Weight Performance:**  Uses an optimized "Pre-Hook" logic and pre-indexed name cache that blocks unwanted data before it is processed in the most efficient way.

Note: PvP Kill Feed option must be ON in your Settings -> Social -> Notifications.

## Settings
Fully configurable via the in-game Addon Settings menu:
`ESC Menu -> Settings -> Addons -> Yudo's Kill Feed`

## Installation
1. Download the latest release (zip file).
2. Extract the folder `YudosKillFeed` to your Elder Scrolls Online AddOns directory:
   - **PC:** `Documents/Elder Scrolls Online/live/AddOns/`
3. Launch the game and enable the addon in the **Addons** menu.
4. **Dependencies:** This addon requires LibAddonMenu-2.0. If you are missing this library, please download it from ESOUI.
