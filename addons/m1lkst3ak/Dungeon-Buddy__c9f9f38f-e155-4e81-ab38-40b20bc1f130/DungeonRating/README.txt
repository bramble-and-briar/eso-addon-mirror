DUNGEON BUDDY v0.3 | Consolidated Corrections

Included:
* Live HUD with current-fight and combat-weighted dungeon DPS/HPS, damage, healing, role-specific uptime, score and pace.
* Automatic End-of-Run report for completion events that ESO exposes to this addon. Report is closable and runs are saved to history.
* Career Profile, history, run details and records within the Dungeon Buddy standalone settings window.
* Controller-oriented menu keybind strip, with History -> Run Details navigation corrected.
* Boss Intelligence reference HUD, up to three mechanics per identified boss.
* Healer buff, tank debuff, DPS DoT and time-on-target measurements and additive role-specific scores.
* Effect uptime now resumes correctly across combat segments when the effect remains active.
* No LibAddonMenu dependency.

Access: Controls > Keybindings > Addon Keys > Dungeon Buddy: Open Settings.

Known limitations:
* This DOES NOT register an entry in ESO's native Settings > Add-Ons category. A verified dependency-free API for that exact registration was not established. The Career Profile is within the standalone Dungeon Buddy settings window, not ESO's native list.
* Effect attribution and DoT/time-on-target measurements are dependent on available game events and include estimates.
* Completion event coverage and gamepad keybind handling require in-game testing.
* No in-game tests were performed; archive integrity alone does not verify ESO functionality.

Addon Settings: Install and enable LibAddonMenu-2.0. Open ESO Settings > Add-Ons > Dungeon Buddy > Open Career Profile. Career Profile, Live HUD, End-of-Run HUD, and Boss Intelligence remain in this build.
