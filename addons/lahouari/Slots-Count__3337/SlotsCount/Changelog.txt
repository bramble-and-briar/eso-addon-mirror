Date: Aug 24, 2026		Version: 2.50.13		by @Dr_Z
====================		================		==========
* Added the guild-trader ownership icon beside Slots Count in the viewer title.
  The viewer now uses the same title icon shown in the Slots Count Settings Menu.
* Guilds the player belongs to are now colored with Slots Count blue in the guild dropdown.
  Scanned guilds the player does not belong to keep their normal dropdown color.
* Added the visible guild count to the ALL GUILDS totals line.
* Selecting one guild hides the guild count and continues showing Users and Listings totals.
* Guild totals follow the current user @name filter.
* Added the /slots short command to the Settings Menu slash-command list.
  /slots and /slotscount both open or close the Slots Count viewer.
* Added a Settings button to the right of Reset Filters in the Slots Count viewer.
  The button opens the Slots Count settings panel directly.
  also Added an Open Settings tooltip and used the existing gears.dds artwork.
* Added a visible message showing the page number and retry attempt when a page does not respond.
* Added completed-page tracking for every page processed during a scan.
  The final scan is not saved if any page from the first through the last page is missing.
  A missed page is retried after the Trading House request timeout.
  After three unsuccessful retries, the scan stops and is not saved.
* Added protection against AwesomeGuildStore Trading House responses colliding with a SlotsCount scan.
* Fixed SlotsCount scans freezing when AGS interrupts an expected page response.
* Duplicate listings are ignored by tracking each listing's unique ID.
* Added scan validation for impossible listing totals over 30.
* An invalid scan is not saved and the previous valid guild scan is restored.
* The Last Scan time is updated only after a successful scan.
* Reworked sortable-header direction handling.
* First click on a header now sorts ascending; the second click sorts descending, then each click alternates direction.
	- User @Name: A-Z / Z-A
	- Item Listings: 1-30 / 30-1
	- Guild: A-Z / Z-A
* Updated the Slots Count viewing window.
	- Normal row text is now explicitly pure white.
	- Sellers in an outside scanned guild are shown in green when their @Name is also found in a guild the player belongs to.
	- Shared-guild membership is cached when viewer data is rebuilt.
	- Added User @Name search.
	- Added numbered rows.
	- Changed row text to white.
	- Added row mouse-over highlighting.
* Added the Slots Count viewing window.
	- Guild dropdown defaults to ALL GUILDS.
	- Displays User @Name, Item Listings, and Guild columns.
	- Added sortable columns and combined user/listing totals.
	- Added a Settings button, /slotscount command, and Show/Hide keybind.
	- Window closes with its close button, the same keybind, Escape, or character movement.
* Version Number Change
