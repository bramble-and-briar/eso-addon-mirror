# One APH a Time

*Withdraw on a stack of recipes, motifs, fragments, containers or furnishings takes one; Get All takes one of everything the settings allow. Learned or opened items are used when you close the storage; furnishings just stay in your backpack.*

## Dependencies

No required dependencies.

Optionals for additional features:
- **LibAPH:** cleans up the memory left after your stored items are used, a little each frame so the game never stutters.
- **LibAddonMenu-2.0:** required for the PC Settings Menu.
- **LibHarvensAddonSettings:** required for the Console Settings Menu.

Without the optional dependencies, the addon still runs entirely independently and can be controlled via built-in slash commands as a standalone utility.

## Slash Commands

- `/oneaphatime`: turns the add-on on or off (so does the Turn One APH a Time On or Off key, Alt+D by default, shown next to Get All at a storage); while it is off, withdrawing takes the whole stack.
- `/oneaphatime chat`: shows or hides One APH a Time's messages in chat (the same as the Chat Logs toggle in the settings). Answers to your own commands always show.
