[SIZE="5"]Description[/SIZE]

SkillExp is a lightweight HUD addon that displays experience progress for skills on your action bars. It shows individual ability rank progression (Rank I–IV) as well as skill line level progress for all skill lines represented on your bars.

The addon displays compact progress bars with XP percentage, rank indicators, and real-time XP gain flashes when you earn experience. Empty action bar slots are automatically hidden to keep the display clean and compact.

Skill lines that receive XP during your session are dynamically added to the display, so you can track progress on crafting, guild, and other skill lines as they level up — even if they have no abilities slotted.


[SIZE="5"]Features[/SIZE]

[LIST]
[*]Front and back bar ability XP tracking with progress bars
[*]Skill line level progress section showing unique skill lines from your bars
[*]Real-time XP gain flash notifications (+XP shown briefly on gain)
[*]Morph indicator when an ability is ready to morph
[*]Dynamic skill line tracking — skill lines auto-appear when they receive XP
[*]Pin skill lines — pinned lines always show (saved per character) and are unpinned automatically once maxed
[*]Draggable, position-saving HUD widget
[*]Detailed tooltips with XP values on hover
[/LIST]


[SIZE="5"]Pinning skill lines[/SIZE]

Open the Skills window and select a skill line — click the pin icon next to its name to pin or unpin it. Pinned lines are marked with a pin in the skill line list.
You can also right-click a skill line bar in the SkillExp display to pin or unpin it. Pinned lines are listed first and stay after reload; when a pinned line reaches max rank the pin is removed.


[SIZE="5"]Hotkey[/SIZE]

In keyboard bindings there is a SkillExp hotkey that acts as a toggle for the main display. Tapping the hotkey twice quickly opens the configuration panel.


[SIZE="5"]Configuration[/SIZE]

Configuration can be opened by command "/skillexp config" or by tapping the Hotkey twice.

Available settings:
[LIST]
[*]Show Skill Percent — display XP percentage next to progress bars
[*]Show Back Bar — show or hide back bar skills section
[*]Show Skill Lines — show or hide skill line progress section
[*]Track Skill Line XP — automatically add skill lines to the display when they receive XP
[/LIST]


[SIZE="5"]Slash commands[/SIZE]

[LIST]
[*]/skillexp — Toggle the skill experience display
[*]/skillexp config — Open the configuration panel
[/LIST]
