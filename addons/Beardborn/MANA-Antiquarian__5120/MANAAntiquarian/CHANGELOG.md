# Changelog

## 1.0.1
- Manifest: minimum versions for required libraries (LibAddonMenu-2.0>=43).
- Settings are now saved per server (EU/NA); existing settings are copied to every server automatically.
- AI disclosure and credits added.

## 1.0.0 — first public release
- Antiquity leads window: your leads grouped by zone, current zone on top, status (Scry / Dig / Other zone).
- One-click scrying and map (tracks the antiquity), double-click to scry.
- Multi-part set progress (e.g. 2/5, completed ×1) with a part checklist in the tooltip.
- "All leads" mode with Display Leads-style filters and hints where to find missing leads.
- Search, sortable columns, resizable window.
- Zones from DLCs you do not own are hidden automatically (adjustable).
- Chat reminder about expiring leads on login.
- Double-click in the Display Leads window starts scrying (if Display Leads is installed).
- English and Russian localization.
