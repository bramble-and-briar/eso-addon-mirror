An_Daghdha1233 Inventory
Creator: An_Daghdha1233
Version: 0.4.1 (local visual update candidate)

The original frame artwork uses a restrained Irish illuminated-manuscript
motif with oak leaves, interlace, and aged bronze. ESO item icons and item
quality colors are retained.

Press Options/Start, then select Inventory in the controller menu to see
equipment above the backpack and item details on the right. Change the
category with L1/R1: All, Gear, Materials, Supplies, Slottable, and Quest. All shows
backpack items; Quest shows the game's separate quest-item inventory.
Supplies includes consumables, furnishings, tools, and other backpack items.
Within Gear, press D-pad up from the backpack grid to select All Gear, Heavy,
Medium, Light, Weapons, Jewelry, or Other. Item details show the armor type
clearly when ESO reports Heavy, Medium, or Light.
Within Slottable, focus a potion, food, or other eligible item and press
Square to open the quickslot picker. Its segmented wheel distinguishes empty
and occupied positions, highlights the selected position, and names the item
currently there. D-pad moves between the eight wheel positions; X assigns
the item to the highlighted position. The positions match ESO's native
consumable wheel. Circle cancels without an assignment.
Move focus with the directional controls. Select a bag item to see its details and
the currently equipped item for the chosen destination. Triggers cycle
valid destinations, including rings and weapon sets. The primary action
equips only after you press it and preserves the game's bind-on-equip
confirmation. The tertiary ESO mode action returns to the world and restores
ESO's native Inventory route. Press Inventory again to enter the native view.
This two-step handoff keeps ESO's protected quickslot wheel functional.
Map Options > Inventory restores this add-on's normal route.
The secondary action opens ESO's native Map from this Inventory view.
The Map retains its original controls, including L1/R1 map navigation.
From the native Map, open Map Options (Triangle on PS5). Quests remains
the opening tab; press L1 once to open this Inventory. R1 from Quests
continues through ESO's native Map Options tabs. On the Map itself,
L1/R1 continue changing map levels.
When a two-handed weapon and an off-hand item displace each other, the
details panel calls out the affected slot before you equip.
Usable backpack items, including reward boxes and bags, show a deliberate
Open or Use action on the primary button. Combination items use the game's
confirmation. Items that can only be used from an action slot are left to
the game's native controls.
Open and Use return to the game view first so ESO can display a loot window,
confirmation, or item effect. Reopen Inventory afterward to inspect the result.

The last category and Gear type are saved per account. Quest items are read-only in this
view; their full native tooltip is available, and native inventory handles
other quest actions.
The quaternary action shows the game's full native item tooltip. Right
stick scrolls longer detail text. Back exits the view.

Only directly comparable item damage and condition-aware armor rating
receive arithmetic differences. Other traits, enchantments, and set
bonuses retain their descriptions. A displayed difference is an item
property difference, not a recommendation or a predicted character stat.

The published 0.4.0 beta passed the owner's PS5 checks for Gear subfilters,
quickslot assignment, and native wheel item use. This 0.4.1 visual update
has PC in-game checks and still requires native PS5 validation.
If the combined view fails, use ESO mode from its keybind or disable
An_Daghdha1233 Inventory in the game's Add-Ons manager to restore the
standard Inventory route.

On PS5, the touchpad opens Map and Options opens the controller menu.
This add-on does not change physical controller bindings. On Steam PC,
the controller layout can translate DualSense touchpad clicks differently.
