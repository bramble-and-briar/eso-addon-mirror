Legitimate global and framework exceptions:
- MountSwap is the single addon runtime namespace; every other Lua module holds
  a local M reference. Ordinary functions/data live under that namespace.
- MountSwapSavedVariables is required by ESO's SavedVariables loader and retains
  schema version 1, account identities and GetWorldName-based server profiles.
- ESO creates SI_BINDING_NAME_MOUNTSWAP_* string constants via ZO_CreateStringId.
- ESO/framework named UI references use MountSwap-prefixed names: MountSwapWindow,
  MountSwapPicker, MountSwapNotice, MountSwapControllerMenu, MountSwapTextEntry,
  MountSwapControllerEdit, MountSwapOptions, MountSwapSettingsSearch_multi/single,
  and MountSwapSettingsSlot1 through MountSwapSettingsSlot8.
- LAMCreateControl is owned by LibAddonMenu-2.0 by Seerah, sirinsidiator and
  contributors. MountSwap registers only its four namespaced widget factories:
  mountswapfavorite, mountswapdashboard, mountswapchattoggle, mountswaprightbutton.
  These registry entries are required framework extensions, not new globals or
  replacement definitions of another addon/library.
- SLASH_COMMANDS is ESO's command registry. Original MountSwap commands and
  configurable aliases register handlers there; alias conflicts preserve the
  existing handler. libAddonKeybinds, LibAddonMenu2 and VOTANS_KEYBINDER are read
  at use/registration time, never created or replaced by MountSwap.
