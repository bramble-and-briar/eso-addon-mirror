ESO Arabic — PC edition
Author: AzoozovicSaw21

Unofficial Arabic localization for The Elder Scrolls Online on PC. Includes Arabic language resources, Arabic fonts, and Arabic text shaping/layout support for supported keyboard and controller UI controls. This is not a console upload package.

Dependencies: No required external addon libraries. Optional compatibility support for AwesomeGuildStore and LootDrop; these addons and LibGetText are not bundled.

Installation: Extract the three folders EsoAR, EsoUI and gamedata directly into your active live/AddOns folder. Preserve the directory structure. When upgrading from the .addon edition, move only EsoAR/EsoAR.addon to a backup location outside AddOns; this PC package uses EsoAR/EsoAR.txt. Keep SavedVariables and other addons. Do not delete the shared EsoUI or gamedata folders.
Enable ESO Arabic. /ar selects Arabic and /en selects English. Restart ESO after installing language files. Switch to English before uninstalling the language pack.

Included formats: .lua and .xml provide addon logic and font definitions; .slug files are converted fonts; .lang and .str files contain game/client localization; language companion .lua files are retained from the existing release. No executables, DLLs, installers or external clients are bundled.

Limitations: Arabic coverage and RTL layout are incomplete. Some native/internal UI text, including excavation/scrying prompts, remains English. This revision addresses publishing format and redundant string guards; it does not claim to fix those remaining gameplay UI issues. New game content requires updated translation data. No future-update or full-compatibility guarantee is made.
