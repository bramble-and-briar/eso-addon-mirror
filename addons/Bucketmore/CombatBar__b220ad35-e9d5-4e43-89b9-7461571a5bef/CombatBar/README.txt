Combat Bar v1.0.0  (PS5 / Console 向け・個人使用)
====================================================

【概要】
自分のスキル効果時間・ULT・クイックスロット・キャスト/チャネル・GCDを表示する独立アドオンです。
Fancy Action Bar+ (v2.19.9) の仕様と動作を参考に、コードは新規に書き起こしています。
FAB+のソースコードの複製・改変は含みません。

【導入】
  ESO/live/AddOns/CombatBar/ に本フォルダを置く。 LibAddonMenu-2.0 が必要。
  設定: アドオン設定 > Combat Bar。 日本語/英語は設定で選択(/reloadui後に反映)。

【実装済みの機能】
 バー表示   標準バー上に効果時間・スタック・ハイライト / もう一方のバーを標準バーの上に表示
            (位置・サイズ・不透明度・彩度) / 標準バーの移動(任意)
 効果時間   カウントダウン・終了間近の色と秒数・小数点表示・表示する効果の秒数範囲・
            スタック数・複数効果・スキル別の効果ID手動設定
 ULT        蓄積量(3形式・発動可能で色変化)・使用後の効果時間
 クイックスロット  クールダウン(長時間対応)・残数
 キャスト/チャネル  スキル使用時の詰め時間を該当スロットに表示
 GCDトラッカー  GCD中だけ更新する縦ゲージ(位置・大きさ・色)
 浮遊エフェクトウィジェット  スキル1つの効果時間を画面上の任意位置に表示(スライダーで位置調整)
 設定       セーブ(アカウント共通)・全初期化・PvE/PvPプリセット・項目別ON/OFF・一括ON/OFF

【実装していない機能(PvPTargetInfoと重複 / 方針により除外)】
 敵バフ/デバフの追跡と対象別表示、味方由来バフの詳細追跡、敵の戦闘状態マーカー、
 ターゲット数カウンター、デバッグ表示。
 ※自分が発動した効果は、敵に付いた場合も「効果中」として最大の残り時間を1つ表示します(対象別の区別はしません)。

【FAB+との同時導入】
 名前空間・保存先・コントロール名はすべて独立(CombatBar / CombatBarSV / CB_*)。
 FAB+が有効な場合、初回起動時に「標準バーの移動」と「もう一方のバー表示」を自動でOFFにします。
 完全な共存は目指していません。表示が二重になる場合はどちらか一方をOFFにしてください。

【効果の対応づけ(FAB+の対応表は使っていません)】
 スロットのスキルIDと同じ効果ID、または同じ能力名の効果を、自動で対応づけます。
 IDも名前も異なる効果は、「スキル別 効果ID設定」で手動指定してください。
 FAB+が持つスキル別の特殊処理(スタック増減の独自計算など)は再現していません。

【軽量化の方法】
 表示更新は「時間付きの効果かキャストがある間」だけ動かし、無ければ停止。
 GCDは使用中だけ20ms更新、クイックスロットはクールダウン中だけ500ms更新。
 ULT・スロット変更・効果変化はイベント駆動。スロット変更は50msにまとめて1回で処理。
