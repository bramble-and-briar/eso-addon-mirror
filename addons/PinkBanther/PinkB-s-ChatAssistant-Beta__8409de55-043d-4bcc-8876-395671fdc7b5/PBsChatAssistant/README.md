# PB’s ChatAssistant 1.30.1

1.30.1では、L2＋右のタブ切り替えが**アナログスティックの右**にも反応していた問題を直しました。
押した瞬間にどちらかのスティックが横に倒れていれば、スティックからの入力とみなして切り替えません。
そのため、スティックを横に倒したまま十字キー右を押した場合（ブロックしながら横移動中など）も切り替わりません。

1.30.0で**グループチャットのタブ**を追加しました。L2＋十字キー右で切り替わる順番は
**通常 → グループ → ギルド1 → ギルド2 …** です。グループタブにはグループチャットだけが流れ、
選ぶと投稿先もグループチャットになります。HUDのタブ名はグループチャットの文字色で表示します。

グループタブは**グループに入っていないときも残ります**。出し入れすると解散のたびに履歴が消え、
切り替えの順番も毎回変わってしまうためです。未加入のまま発言しようとした場合は、
ゲーム本体が送信時にその旨を表示します。通常タブのグループチャット表示は従来どおりです。

1.29.2では、ChatFilterと同じギルド勧誘メッセージおよびNPC会話の非表示機能を追加しました。
ゲームが挿入するギルドリンクを判定するため、勧誘文の言語に関係なく動作します。

設定画面からHUDの現在タブ名表示をオン／オフできます。
表示をオフにしても、タブ切り替えと投稿先の同期はそのまま動作します。

戦闘開始イベントの状態を保持し、戦闘中はL2＋十字キー右の切り替えと
入力抑止レイヤーを確実に停止します。

設定画面の「通常チャットに表示」には加入中のギルド名を正しく表示します。
設定画面はギルド情報が揃ってから生成されるため、番号や空のスロットではなく実名が並びます。

**現在選択しているチャットタブ名をHUDに表示**します。通常タブは白、
ギルドタブはそのギルドチャットと同じ文字色です。表示位置と文字サイズは設定画面で変更できます。
ギルドタブを選ぶと投稿先もそのギルドへ切り替わるため、そのまま発言できます。
ログイン時の投稿先を設定している場合は、ログイン時のアクティブタブも同じ投稿先へ合わせます。

ギルドごとのチャットタブ（1.18.0）はそのままです。通常タブに加えてギルドごとのタブを作り、
そのギルドチャットとオフィサーチャットをそこへ流します。**L2＋十字キー右でタブを切り替え**ます。

ESOコンソール版のチャット入力補助と、HUDでの投稿先チャンネル切り替え。

**戦闘中はL2＋右による投稿先切り替えを無効にします。** 戦闘開始時に右の入力レイヤーとクエスト切り替えの遮断を解除し、戦闘終了後に再開します。

## HUDでの切り替え

1. チャット入力画面を閉じ、通常のHUDに戻ります。
2. **L2を押したまま十字キー右を押します。**
3. L2を保持したまま十字キー右を押すたびに、次の投稿先へ切り替えます。
4. L2を離すと、十字キー右の通常操作へ戻ります。

L2はバインドせず、押し込み量を読みます。PBsScreenshotModeShortcutと同様に、防御状態も補助判定に使います。L2が標準の防御割り当てであることを前提にしているため、防御を別キーへ変更した場合はそのキーでの防御中も反応します。

右の入力レイヤーとクエスト切り替えの遮断は、L2保持中だけ有効です。同時押しとして右を押した後は、L2を先に離しても右の解放処理が終わるまで保持します。右のリピート通知による連続切り替えは防ぎ、押し直すたびに次の投稿先へ進みます。

L2を少し先に押してから右を押してください。入力レイヤーの更新周期は10msで、実際の反映はゲームのフレーム更新にも依存します。L2を押した瞬間と完全に同じフレームに右を押した場合の捕捉は保証できません。

文字入力画面、メニュー、Enter捕捉中は切り替え用レイヤーを外します。エリア移動・コントローラー切断でも解除し、復帰後に再開します。入力解放の通知が欠落した場合は、右の保持状態を5秒で解除します。L2自体の保持には時間制限を設けません。投稿先はチャットログに表示します。

**今回のL2＋右とクエスト切り替え抑制は実機未確認です。** `lua test/hud_channel.lua`で入力状態とXMLの回帰テストを実行できます。更新後は「L2単独の防御」「右単独のクエスト切り替え」「L2＋右で投稿先のみ切り替わる」「L2を先に離してもクエストが切り替わらない」「L2＋左のスクリーンショットモードとの併用」を確認してください。

## タブ

- 通常タブ＋ギルドごとのタブ。タブ名はギルド名です
- 現在加入しているギルド数だけ生成し、脱退済み・改名前・重複タブは再同期時に整理します
- オフィサーチャットは、そのギルドのタブにまとめます
- **L2を押したまま十字キー右**で次のタブへ移ります
- ギルドに入る・抜ける・改名した場合は自動で追従します
- 現在のタブ名をHUDに表示します。通常タブは白、ギルドタブはギルドチャットの文字色です
- ギルドタブを選ぶと、次の発言先もそのギルドチャットへ切り替わります
- 投稿先をゲーム側で変更した場合も対応するタブへ同期し、通常タブでは非ギルド投稿先を復元します
- 現在のタブ名はHUDだけに表示し、メニュー画面では非表示になります

タブはESO本体のチャット設定に保存されるため、毎回作り直しはしません。
機能をオフにすると、このアドオンが作ったタブだけを削除し、ギルドチャットを通常タブへ戻します。

## 設定

設定 → アドオン → PB’s ChatAssistant

| 項目 | 内容 |
| --- | --- |
| L2＋十字キー右でタブを切り替える | HUDでの切り替え機能のON/OFF（`/pbchat hudchannel` と同じ） |
| ギルドごとのチャットタブを作る | タブの作成・削除（`/pbchat tabs on\|off` と同じ） |
| 通常チャットに表示: ギルド名 | **ギルドごとに**通常タブへ流すかを設定（`/pbchat guildinmain <1-5> on\|off` と同じ） |
| ギルドリンクを含むメッセージを非表示 | ギルドリンク付きの勧誘を非表示（初期状態はOFF） |
| ウィスパーも対象にする | 送受信ウィスパー内のギルドリンクも対象にします |
| NPCの会話を非表示 | NPCの発言・叫び・ウィスパー・エモートをチャットログから除外 |
| 現在のタブ名を表示 | HUDのタブ名表示だけをON/OFF。タブ切り替えと投稿先同期には影響しません |
| 現在のタブ名: 横位置／縦位置 | HUDに表示するタブ名の位置 |
| 現在のタブ名: 文字サイズ | HUDに表示するタブ名の大きさ（14～72） |
| 現在のタブ名: 描画レイヤー | 背景／コントロール／テキスト／オーバーレイから選択 |
| ログイン時の投稿先 | セッション開始時の投稿先。「変更しない」で無効 |
| 開くまでの待ち時間 | 文字入力画面が出るまでの待ち時間 |

「ログイン時の投稿先」の選択肢は**パネルを開くたびに作り直します。** アドオンのロード時点では
ギルド所属が確定しておらず、ギルド名の代わりに `/g1` のようなコマンド表記になったり、
そもそも一覧に出なかったりするためです。

適用はログイン後の数秒後に一度だけです（ギルド所属の確定を待つための遅延）。投稿先が
ギルドまたはオフィサーチャットならそのギルドタブ、それ以外なら通常タブも選択します。
エリア移動やロード画面を挟んでも再適用しません。使用できないチャンネルは適用しません。

## ギルド勧誘フィルター

ギルドファインダーの「チャットにリンク」で挿入されるギルドリンクを含むメッセージを
チャットへ追加する前に除外します。文章だけの勧誘、通常会話、アイテムリンクなどは対象外です。
ギルド／オフィサーチャンネルと自分の発言は常に表示します。ウィスパーは初期状態では表示し、
「ウィスパーも対象にする」をオンにした場合だけ除外対象になります。

## NPC会話フィルター

NPC専用の発言・叫び・ウィスパー・エモートチャンネルを、チャットログへ追加する前に
除外します。プレイヤーの発言には影響しません。字幕は別のUIであるため、設定をオンにしても
画面上では従来どおり表示されます。初期状態はオフです。

## コマンドと診断

- `/pbchat hudchannel off` / `on`：HUDショートカットを停止・再開。
- `/pbchat entrychannel off` / `on`：互換用の別名。新しいHUDショートカットへ適用します。
- `/pbchat hudstatus`：L2の読み取り値、十字キー右の受信回数、レイヤー状態、エラーを一度だけ表示。
- `/pbchat binds`：実際に宣言している十字キー右アクションと継承元を表示。
- `/pbchat forcelayer`：旧強制モードは廃止。通常操作を妨げるレイヤーを強制維持しません。
- `/pbchat safe`：既存のEnter捕捉を停止してコントローラー操作へ戻す。
- `/pbchat recruit on|off`：ギルド勧誘フィルターをON/OFF。
- `/pbchat recruit whisper on|off`：ウィスパーも対象にするかを変更。
- `/pbchat npc on|off`：NPCの会話をチャットログへ表示するかを変更。

以前の試行でHUD切り替えを無効にした保存設定とは別の `hudChannelEnabled` を使い、今回の新機能は初期状態で有効です。
アドオン全体のオフ設定やEnter捕捉設定は維持します。

## チャット入力補助

コントローラーで通常どおりチャットを開いたときに、本体の文字入力画面を出す既存の監視処理を維持しています。
Enterで開きたい場合は `/pbchat enter` で捕捉を有効にします。
設定 → アドオン → PB’s ChatAssistantから、入力画面を開くまでの待ち時間を調整できます。

## 導入

LibHarvensAddonSettings（20106以上）が必要です。
旧フォルダを更新版で置き換え、`/reloadui`または再ログインしてください。更新後はアドオン一覧のタイトルで1.30.1を確認してください。旧版やPBsHUDChannelProbeなどの別アドオンが同時に有効なら、それらの割り当てはこの変更では削除されません。
ZIP内のPBsChatAssistantフォルダを使い、別のPBsHUDChannelProbeは無効にしてください。
元の配置ソースは `PBsChatAssistant-1.13.1-source-backup.zip` に保存しました。
