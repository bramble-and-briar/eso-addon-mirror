ESO Arabic 2.3.5 - PC

Close ESO completely and back up existing Arabic addon files. Extract this ZIP
directly into the active Elder Scrolls Online/live/AddOns directory, merging
the three top-level folders: EsoAR, EsoUI and gamedata. Replace matching files.

Expected paths:
AddOns/EsoAR/EsoAR.addon
AddOns/EsoUI/lang/ar_client.str
AddOns/EsoUI/lang/ar_pregame.str
AddOns/gamedata/lang/ar.lang

Do not add an ESO_Arabic wrapper folder. Move any obsolete nested copy to a
backup location outside AddOns. Keep SavedVariables and unrelated addon files.
Never delete shared EsoUI or gamedata directories. Enable EsoAR; use /ar to
select Arabic, then restart ESO completely. Before uninstalling, use /en while
the addon is installed, and then close ESO completely.

If updating through Minion, the public download must first be updated to this
release. An older public download may reinstall the older addon version.

See CHANGELOG.txt for changes and verification limits. Test research, alchemy,
enchanting, chat and quest rewards in game before publishing this release.
