# 2.0.0

- ALTHI becomes ALTHI Suite: Gathering and Gold under a shared, configurable HUD.
- Add an independent survey overview with shared profession filters, area counts, inventory/bank summaries, envelope opening and native player/wayshrine travel.
- Add Current/Lifetime refining results for the four refining professions, auxiliary conversions and weighted yields per 100 raw materials.
- Add account/character gold accounting, guild attribution via optional LibHistoire, trade-period filters and optional own-sales history import.
- Separate total session time from active time; material gold/hour uses total session time, including travel while running.
- Preserve existing saved settings, prices, sessions and lifetime data. Item names follow the ESO client; seven interface languages are bundled.
- Replace the main HUD’s one-second full rebuild with lightweight text updates. Visible travel quotes reuse resolved targets without repeated list/roster/node searches.
- Unified controls, compact views, opacity, saved survey placement and additional optional keybindings.
