# 1.0.0 – 27 October 2026

First 1.0 release, combining resource gathering and fishing.

- Resource and Fishing tabs in one shared session, with automatic and manual view switching.
- Crafting/provisioning materials, supported creature/container loot and Luminous Ink tracking.
- Fishing-only active time, catch/fish rates, bait display, optional bait selection and player-started sequential filleting.
- Session/lifetime fishing statistics and observed Perfect Roe results; lifetime reset is separate and confirmed.
- Pause/Resume and Reset controls; optional resuming on a real find, with clickable header switches for resume policy and guild-trader valuation.
- Session-scoped stock comparison, optional price integrations/custom prices and consistent optional 7% sale deduction.
- Searchable material filters, documented source hints, native icons/colors, adjustable overview and optional keybindings.
- Consistent button styling, smaller binding hints and three-second fading rare-find notifications.
- Seven bundled interface languages; no separate packs. Five translations remain drafts.
- Existing saved-data identity, filters, prices and keybindings retained. Prior Run/Stop bindings map to Resume/Pause.
