# MANA Antiquarian

Автор: **Beardborn**. English version: [README.md](README.md)

Аддон для The Elder Scrolls Online (ПК): удобное окно зацепок древностей (раскопок).

Раньше назывался **MANA Leads**.

## Как открыть

- Команда `/manadig` (или `/manaantiquarian`; старая `/manaleads` тоже работает)
- Или своя клавиша: Настройки → Управление → **MANA Antiquarian → «Открыть MANA Antiquarian»**

Окно закрывается крестиком или Esc, его можно перетаскивать и **растягивать мышкой** за край. Размер и положение запоминаются.

## Режим по умолчанию: мои зацепки

Показываются только зацепки, которые у вас **есть**, сгруппированные по зонам:

- **текущая зона — сверху** с пометкой «◆ … — вы здесь»;
- потом зоны, где место раскопок уже найдено;
- потом остальные по алфавиту.

Также показывается **простая зацепка зоны** (у каждой зоны есть своя, например «Гадальные кости» в Рифте): она не требует зацепки и лоцируется всегда. Чтобы список не забивался такими зацепками из всех зон, она показывается только для **текущей зоны** или если уже начата (лоцирована / найдено место раскопок).

Колонки:

| Колонка | Что показывает |
|---|---|
| Статус | **Копать** — место раскопок уже найдено; **Лоцировать** — можно лоцировать прямо сейчас; **Недоступно** — вы в нужной зоне, но лоцировать нельзя (подземелье, бой, не хватает навыка); **Другая зона** |
| Древность | Название цветом по качеству |
| Набор / награда | К какому набору относится (мифик, маунт, шкатулка…) или какая награда. Для составных наборов — **прогресс сбора**, например «2/5» (серым — ничего не собрано, жёлтым — частично) и «собрано ×1», если набор уже собирался целиком |
| Записи | Сколько записей кодекса (истории древности) открыто, например «1/3». Новая запись открывается при каждом раскапывании |
| Срок | Сколько осталось до исчезновения зацепки: в днях; меньше суток — в часах (оранжевым), меньше часа — красным |
| Лоцировать | Запускает лоцирование (если можно) |
| Карта | Открывает карту зоны и отслеживает эту древность — участки раскопок видны на карте |

**Сортировка:** щелчок по заголовку колонки (Статус, Древность, Набор, Записи, Срок) сортирует зацепки внутри каждой зоны (по «Набору» — сначала самые собранные наборы), повторный щелчок меняет направление. Сами зоны остаются в прежнем порядке (текущая — сверху). Выбранная сортировка запоминается.

**Двойной щелчок** по строке тоже запускает лоцирование. Если лоцировать нельзя, в чат приходит объяснение почему.

При наведении на строку — стандартная карточка зацепки, **список всех частей набора** (✓ — собрана, иначе — есть ли на неё зацепка) и описание, где её искать.

Прогресс считается по текущему «кругу»: часть собрана, если её выкопали больше раз, чем самую редкую часть набора. Так для повторяемых наборов видно, сколько осталось до следующей сборки.

Сверху сводка: сколько всего зацепок, сколько можно лоцировать здесь и сколько уже ждут раскопок.

## Переключатель «Все зацепки»

Включает в список и зацепки, которых у вас **нет**, со статусом «Нет зацепки» и подсказкой, **где их искать**. Они группируются по зоне, где добывают зацепку. Появляются два фильтра (как в Display Leads):

- **Основной:** «Можно найти» (всё, кроме завершённых неповторяемых), «Не все записи кодекса», «Ни разу не выкопанные», «Групповые подземелья», «Последнее DLC», «Все».
- **Тип:** «Все типы», «Скрыть обычные» (главы мотивов, простые сокровища и простая мебель), «Только составные» (части наборов).

Фильтры действуют только на недостающие зацепки — свои показываются всегда.

## Поиск

Поле поиска ищет по названию древности, зоне и набору.

## Зоны из дополнений

Зацепки в зонах из **недоступных вам дополнений** скрываются автоматически — аддон спрашивает у игры, открыт ли у вас нужный коллекционный предмет (DLC/глава). В настройках (`/manadigsettings`) есть список зон из дополнений с галочками: можно скрыть ненужную зону или, наоборот, показать. Кнопка «Сбросить к автоопределению» возвращает всё как было.

Ограничение: проверяется зона, где добывают зацепку или копают. Если зацепка выпадает в подземелье или испытании из отдельного DLC, а зона при этом базовая, — такая зацепка не скроется.

## Напоминание об истекающих зацепках

При входе в игру в чат приходит список зацепок, которые скоро исчезнут. Порог настраивается: меньше 1 часа / 1 дня / 7 дней (по умолчанию — 1 день). Проверить вручную: `/manadig alert`.

## Display Leads

**Display Leads не обязателен**, но если он установлен, MANA Antiquarian берёт из него:

- описания, где искать зацепки;
- зону, где добывают зацепку, если она отличается от зоны раскопок;
- данные для фильтров «Групповые подземелья» и «Последнее DLC».

Кроме того, в окне самого Display Leads двойной щелчок по строке тоже запускает лоцирование. Сам Display Leads не изменяется, его можно спокойно обновлять.

## Команды

- `/manadig` — открыть/закрыть окно
- `/manadig alert` — проверить истекающие зацепки
- `/manadig help` — список команд
- `/manadigsettings` — настройки

## Установка

1. Нужна библиотека **LibAddonMenu-2.0**. Display Leads — по желанию.
2. Скопируйте папку `MANAAntiquarian` в `Документы\Elder Scrolls Online\live\AddOns\`.
3. Включите MANA Antiquarian в списке аддонов.
